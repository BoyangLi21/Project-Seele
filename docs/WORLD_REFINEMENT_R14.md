# R14：抱缚演出、建筑饰面与金字塔连接

本轮按负责人要求继续当前 `SEELE_TV_WORLD_PREVIEW_20260906`。地图回读、实走、战斗录像和重载复验已完成，进入人工观感验收。所有世界差量、私人模型及动捕衍生文件保留在本机，不进入发布资源。

## 战斗与驾驶

负责人指出的最后抱住自爆，旧版通过把倒地骨架混到收拢姿势并移动根节点实现，产生了吸附、肢体穿过身体的问题。本轮保留 23 秒事件顺序，重做接触开始、四肢缠绕、躯体包覆和初号机的支撑反应。

参考 TV 第 2 话第 301–305 镜：使徒先抬头，四肢变成长鞭状，再缠住初号机并改变身体形态，核心接近初号机头部。这里采用非人形变形；前段仍使用 R12 的真人动作来源及接触修正。参考对照：[Episode 02 Scene 07b](https://wiki.evageeks.org/FGC:Episode_02_Scene_07b)。

- 骑乘压制时，按实际髋部位置展开支撑脚，约束膝部高度；最后一次击打后先撤回支撑手。
- 16.3–18.6 秒按连续的外侧弧线伸展、缠绕，躯体随后收拢。初号机同步起身、收臂和挣扎。
- 用实际绘制的装甲顶点建立整个短片段的保守包络。曲面保留径向厚度，避免直接压到同一表面。
- 对变形后被拉长的三角形进行保留 UV 的连续细分，防止“顶点在外、三角面穿过身体”。每条被细分的共享边在两侧同时处理。
- 原始时刻的 70 个姿势及包含中间插值的 139 个姿势均执行了跨角色三角形检查：Blender BVH 筛选后再做三角形分离轴检查，冲突数为零。这是该片段的采样结果，不代表所有战斗动作的连续碰撞证明。
- 摄像机进入和退出该镜头均连续过渡。普通驾驶的跳跃／动作分支摄像机改为按渲染帧插值，并对来源切换的偏移作短衰减；速度造成的视野变化也采用连续时间滤波。

私人回放由同一份骨骼、位置、眼睛和镜头曲线驱动。额外曲面文件与回放、原模型的 SHA-256 绑定；文件缺失或不配套时回退到既有回放。曲面在模型加载时预热，帧间采样不分配每顶点临时对象。整个电影文件、曲面缓存及其中第三方模型／非商业动捕内容不提交 Git。

## 地图

### 饰面与机库

实际存档中实测的 291,258 块 `minecraft:reinforced_deepslate` 已替换为原创 `projectseele:nerv_structural_panel`。保留原有碰撞和强度，改为平整涂装板。生成器、平台渲染及维护逻辑统一使用该饰面；结构识别标签同时接受旧材料，兼容未迁移的旧存档。

部分旧路线描述器会在 Forge 注册事件之前加载，因此结构板的状态改为延迟读取，不能在这些描述器的静态字段中调用未注册的 `RegistryObject.get()`。创造栏、物品模型和中英文名称同时补齐。

### 金字塔

- 屋顶电梯出口围成接待房间，加入连续墙顶、接待台、状态屏、座椅区、地毯和绿植。
- 原钢琴整体移动 `(-14,-1,-4)`，谱架内的书及其 NBT 保留；蓝色背板改为黑色。
- 新侧廊从屋顶接到原东侧环廊，使用真实楼梯处理三格高差，顶棚随梯段降低并封闭接缝。
- 新侧廊首次实走发现入口缺一格地板、首级高差过大，已修正并重新实走。
- 顶部会客厅保留原入口：从电梯上层走到西侧楼梯，再通过 X=10/11、Z=311 的可开合门板。检验调用真实开门动作并在结束后恢复门板状态，没有在黑色展示墙中另开洞。
- 两层已命名的职员休息区补充家具、储物、台面、照明和绿植。

大指挥室保护范围 `X=2..52 / Y=-449..-391 / Z=244..366` 的 370,107 个实测单元在归一化本轮材料替换后，方块类型／位置变化为零。顶部 2,344 块单向观景窗及对应方块实体保留。

### 景观

在已测量的自然地面上细化湖岸和林下植被，保持原地形高度，避开工程设施及未知单元。GeoFront 西侧／南侧、东京西缘和箱根东缘共修改 7,161 个岸线地表单元，增加 23,938 个低矮植被单元；没有向道路或轨道净空放置植被。回读检查没有发现本轮岸线换材留下不受支持的草／蕨。
