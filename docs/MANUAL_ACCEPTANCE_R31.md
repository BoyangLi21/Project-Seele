# R31 人工验收：战斗、横向空运与双机库

使用同批 R31 客户端、服务端、存档，网络协议 **35**。新世界目录是 `SEELE_R31_WORLD`，保留本轮冷备份中的 R30 玩家、剧情、NPC 和交通进度；原 `SEELE_R30_WORLD` 与 R30 五包仍保留。

本说明列出操作方法和观察重点，不等于这些项目全部通过了自动测试。实际记录在五包内的 `R31_BATCH.json`；若 `acceptance_mode` 为 `manual_by_user`，相应最终体验或专用服务器检查留待人工确认。

## 从哪个入口启动

仓库本地运行：

```bat
start_eva_test_r31.bat
```

开启光影用 `start_eva_test_r31.bat --city-shaders`，关闭用 `--no-shaders`。`--check` 只准备启动命令，不进入世界。BAT 需要最终 `r31_ready.json`、正式模型包和 R31 动作文件；只有施工副本时会提示尚未完成安装。

PCL 用户将 Client 包解压到对应 Forge 1.20.1 版本的独立游戏目录。单机把 World 包解压到 `saves/SEELE_R31_WORLD`；连接服务器则不必在本地安装完整 World 包。

## 优先验收战斗手感

先按同目录 `FIRST_ACT_R31_CN.md` 启动萨基尔任务，用初号机进行测试。完整的脚步、蓄力、受击和接触需要看连续过程，不仅看命中瞬间。

| 默认按键 | 操作 |
| --- | --- |
| WASD／Ctrl | 行走／奔跑 |
| 空格 | 跳跃；趴姿不能直接起跳 |
| Shift／Z | 下蹲／切换趴姿 |
| R | 切换已经取得的武器 |
| 左键／右键 | 地面普通攻击或射击／近战重击 |
| 空中左键 | 近战跳击 |
| 空中右键 | 向下砸击，落地时结算接触 |
| 逗号键 `,` | 空手双手抓取；抓住以后再按逗号投掷 |
| 抓住后左键 | 投掷 |
| G | AT 力场 |
| V | 脱离机体／弹出插入栓 |
| O／F5 | 指挥通信／切换视角 |

默认抓投键为逗号 `,`，避开原 Y 键与其他模组的冲突。已有自定义键位以游戏设置为准。抓取要求站立、空手、面向附近的可抓取使徒；先用拳或刀削弱萨基尔的力场，再收起武器按逗号。距离不够或力场仍阻挡时，聊天栏会说明原因。剧情演出、机库联锁、趴姿和失去驾驶控制时不能强行抓取。

建议顺序：

1. 空手短距离普通攻击、重击，接着移动和跳跃，观察动作衔接与重心。
2. 跳起后左键攻击，再试跳起后右键下砸；观察手臂前驱、落地制动及实际接触。
3. 削弱萨基尔力场，靠近后按逗号。应看到伸手、接触和抓稳过程，不能瞬间把使徒吸到胸口。
4. 抓住后再按逗号或左键。观察骨盆、胸廓与手臂是否一起发力，以及使徒离手、飞出、落地的先后关系。
5. 分别承受正面和侧面攻击，观察后退、失衡、恢复，以及驾驶视角的冲击反馈。倒地后的起身应先用手撑住，再建立脚部支撑、抬起骨盆并站稳，不能只把整个人形旋回竖直；留意手掌和脚底是否穿地或滑走。

新增跳击、落地砸击和投掷的单次**基础伤害为 35**；它们此前没有对应独立招式。原有拳、地面重击、刀和枪伤害没有在本轮随之提高。实际扣血仍受 AT 力场和原护甲结算影响。

两台 UN 使用各自的膝肘位置重定向。请留意握持和投掷时手指、手腕、膝盖及装甲接缝，尤其比较站姿与受到冲击时的差别。

## 两个 UN 机库和复位

```mcfunction
/give @s projectseele:un_satellite_phone
/un phone
/un status
/seele military visit hangar
/seele military un01 visit control
```

UN-00 原库位：`6442.5 77 -6205.5`。UN-01 原库位：`6282.5 77 -6205.5`。两库都朝 **+Z** 出库，位于城市东北方向的远端军事基地；直接以坐标或电话导航为准。

每库外壳宽 133 格，湿舱和机体大门净宽 49 格、净高 65 格。维护廊移到更外侧，原插入栓登机点保留。人员从原入口进入后，经控制室西侧通道到后方原楼梯。大门现在向顶部四段叠收，人员入口不在门片扫掠范围内。

管理员维护复位：

```mcfunction
/seele military reset 00
/seele military reset 01
```

分别复位一次，观察：机体仍为正确型号；手、眼睛和装甲没有错骨；插入栓显示位置与可交互位置一致。不要在正在验收运输动画时连续反复复位；维护复位会接管并结束该机体当前机械流程。

```mcfunction
/un drain 00
/un door 00
/un fill 00
/un drain 01
/un door 01
/un fill 01
```

排液完成后才能开门。机体归位、驾驶员离开并关好门后才能注液。两库保留源存档各自的开门／注液状态，所以刚进入世界时不一定处于相同阶段。

## 横向空运

```mcfunction
/un deliver 00 32 195
/un deliver 01 -800 600
/un recover 00
/un recover 01
/un cancel 00
/un cancel 01
```

UN 电话可选择机体和目标 X、Z。系统检查地面与净空，必要时在附近寻找安全落点，并报告最终坐标。不要仅根据输入坐标认定最终落点完全相同。

本轮重点看：地面接载 → 夹具接触 → 逐渐收身并俯卧横置，脸朝地面、背朝飞机 → 降落前翻回竖向 → 接地和释放。专用鞍座与伸缩支撑应始终可见；原机体与原插入栓持续跟随，EVA 脚下不再吊着原 NERV 地面转移架。分别试有人驾驶与无人／损坏机体。

回收到 UN 基地后，机体先停在门外接应平台。等待运输结束，再请求：

```mcfunction
/un dock 00
/un dock 01
```

NERV 机体使用 NERV 电话里的「运输部门」，运输机在机场 `1200.5 84 20.5` 待命。地下机库中不能直接穿屋顶起吊；先正常发射至地表。空运回收后停在原地表发射井顶部，接着由指挥室下达常规回收：

```mcfunction
/seele eva recover unit00
/seele eva recover unit01
/seele eva recover unit02
```

取消和暂停应保留当前机体，不能在空中凭空卸货。若测试中出现「运输暂停」，先查看聊天栏具体原因，再处理障碍或取消；遇到无法恢复的状态，记录坐标、机型、运输阶段和是否载人。

## 脱离、损坏与电力

按 V 脱离后，等插入栓真正落地、人员离舱，再靠近左键攻击外壳清除它。仍载人、仍在飞行或仍挂接机体的插入栓不能用这个方式删除。销毁与暂时未加载是不同状态；系统不会因为 UUID 未加载就自行生成替代栓。

机体零血、无人驾驶和电源耗尽应分别保留相应关机表现。查看空运接载、横置、卸货后是否连续，特别留意有没有突然站起来。UN-00／01 为核能，不连接电缆；UN-01 离开机库后可站立按 F 开启背部喷气飞行。WASD 移动、空格上升、Shift 下降、Ctrl 加速，F 请求降落，K 眼部激光。

原 NERV 机体的电缆应接到背后红色接口区域，不穿到胸前。零号机蹲下时不应再出现有问题的旧实体盾模型；AT 力场仍用 G。

## 对白、广播和画面

右键工作人员，观察聊天栏文字。人物发言不应再播放角色配音；设施 PA、机械音和公共交通广播仍保留。美里、律子、冬月、摩耶和三驾驶员的语气应有区别；警卫只能完成本岗位职责。

光影开启后，大指挥室灯光可用总指挥席后 `26 -405 275` 拉杆控制。纹理和光影仍使用两个独立安装包，解压进 PCL 对应版本的游戏目录，已经附带原始 ZIP，无需再下载。

验收反馈最好包含机型、坐标、动作顺序和短录屏。动作看起来是否有重量、是否好操控，仍以这次人工体验为准。
