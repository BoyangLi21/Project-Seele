## 2. 初号机：亲自登机、发射、驾驶、回收

先到初号机上层观察廊。此处已核对实际存档：脚下 Y=-395 有地板，站立高度为 -394。

```mcfunction
/execute in projectseele:geofront run tp @s 30.5 -394 -123.5 0 0
/seele eva status unit01
```

正常起点是 `phase=PARKED`。沿机体两侧的上层栈桥绕到背后，面对悬吊插入栓的舱口，空手右键。进入后再发整备指令。不要直接右键腿部，也不要飞到机体胸口尝试登机。

如果聊天栏明确提示插入栓被 DUMMY 占用，先执行下列指令，再重新登机：

```mcfunction
/seele eva dummy stop unit01
```

自己坐进插入栓后：

```mcfunction
/seele eva prepare unit01
```

观察顺序：舱内准备、桥段收回、EVA 低头、背板打开、吊机送栓、锁紧合盖、抬头亮灯、排液、平台转运至发射井。用下面的状态指令确认整备已经完成，不要一次性把整备与发射指令全部粘贴执行。

```mcfunction
/seele eva status unit01
```

等 `phase=SILO_READY` 后，再执行：

```mcfunction
/seele eva launch unit01
```

独自驾驶时也可在发射锁定状态按 **X**。**C** 仅在尚未发射的锁定阶段申请取消并回机库。零号机、贰号机的指令分别把 `unit01` 换成 `unit00`、`unit02`；这三个编号不包含 EVA-UN-00。

驾驶键位：

| 按键 | 操作 |
| --- | --- |
| W / A / S / D | 移动 |
| Ctrl + W | 奔跑 |
| Space | 跳跃 |
| 按住 Shift | 下蹲；松开起身 |
| Z | 趴下／起身；趴下时 W 前爬 |
| R | 切换武器，以 HUD 当前武器为准 |
| 左键 | 普通攻击；步枪模式为开火 |
| 右键 | 空手重击；步枪模式按住瞄准；其他武器依 HUD 提示 |
| B | 近战踢击 |
| G | AT 力场开关 |
| V | 申请退出 EVA／拔出插入栓 |
| F5 | 第一／第三人称 |

建议按“站立走 → 跑 → 跳 → 落地继续跑 → 蹲走 → 趴行 → 起身”连续测试，再切步枪分别站射、蹲射、卧射：按住右键瞄准，左键开火。看脚是否打滑、膝盖是否异常折叠、枪托是否跟随身体、弹道是否从枪口发出。空手右键重击应没有爆炸效果。步枪是左键开火，不要把其他武器的右键蓄力当成步枪操作。

回收时把机体走回自己的地面发射／回收板，停止移动，然后发回收指令。表中 Y 是 EVA 脚部高度，不是驾驶员眼睛高度。

| 机体 | 地面回收板中心 X / Y / Z |
| --- | --- |
| EVA-00 | -11.5 / 81 / -35.5 |
| EVA-01 | 30.5 / 81 / -35.5 |
| EVA-02 | 72.5 / 81 / -35.5 |

```mcfunction
/seele eva recover unit01
/seele eva status unit01
```

回收必须由 `DEPLOYED` 状态、对应回收板、静止机体发起。等待下降、回笼、退栓、恢复湿舱，最终再次变成 `PARKED`。不要在驾驶中用玩家传送指令换景；先完成回收、离开机体，再去车站。

## 4. 初号机与使徒的战斗演出

亲自驾驶初号机发射后，在聊天栏下达任务：

```mcfunction
/seele firstbattle begin
/seele firstbattle status
```

驾驶初号机前往东北迎击大道 **X=356.5、Z=-459.5，路面站立高度 Y=81**。接近目标区 90 格内才会部署任务使徒；只把玩家传送过去、驾驶 EVA-UN-00 或使用 DUMMY 都不能替代这一步。

攻击使徒、削弱其 AT 力场和血量。使徒血量不高于 32% 时，初号机需站立着地、双方距离约 14–46 格、周围有足够空间，之后一次合适的攻击会触发约 23 秒自主作战演出。不要保持蹲姿、趴姿或 N2 武器。

看膝盖和脚尖的支撑、腾跃后的落地收势、最后使徒的接近与锁臂，以及结束后驾驶控制是否恢复。演出中按 **Enter** 跳过；不要打开聊天栏后再按 Enter，那是在发送聊天。

放弃尚未完成的任务：

```mcfunction
/seele firstbattle cancel
```

完成或取消后可重新 `begin`。该任务有自己的使徒身份，不需要额外 `/summon`，也不需要用 `/kill` 清场。

这些是自动运行的 MTR 服务。等列车停稳、站台一侧车门打开，**从车门正常走进去**，再往车厢中央走两步。不要创造飞行着穿过模型，也不要按住 Shift 上车。无需右键车头或打开驾驶台。

先测试 **P1 城市—港口联络线**，传送到城市站台：

```mcfunction

```

1. 落地，等 P1 停稳开门；它是双节小型电车，港区停车约 12 秒。
2. 从打开的车门步行进入。开车后，人物应随车移动；留在站台说明没有进入有效车厢地板。
3. 到港口停稳后从开门处走出；需要解除乘坐状态时按 **Shift**，再走到站台。不要在行驶中测试下车。
4. 返程仍在港口站等 P1。火车按自己的运行循环到站，传送到车站不会立即召来一班车。

## 6. 乘坐飞机

客运飞机是 **F1 箱根湾—新箱根联络航班**，自动滑行、起飞和降落。它与 UN 基地里的 Superb Warfare 战斗机使用不同的乘坐／驾驶系统。

箱根湾机场登机梯下方：

```mcfunction
/execute in projectseele:geofront run tp @s 669.31225 81 1232.5 0 0
```

新箱根机场登机梯下方：

```mcfunction
/execute in projectseele:geofront run tp @s -1628.31225 81 -217.5 0 0
```

1. 站在梯下等 F1 客机到达机位、停稳开门。飞机可能正在另一机场或飞行途中，不能从空机位登机。
2. 顺着登机梯往南走（Z 增大的方向），从打开的舱门进入，再向客舱里面走几步。以实际打开的舱门为准，不要对着机身或机翼穿过去。
3. 停止输入，等待航班自动离开机位；乘客不需要油门、起落架或发射指令。
4. 到另一机场时，等它滑行到机位、完全停稳开门，再走到出口并按 Shift 解除乘坐、沿梯下机。

**R19 已完成实际乘客往返验证：** 从登机梯正常步行入舱，两端停靠开门，往返约 12 公里，服务端乘客登记及移动连续性通过。针对旧版 25–36 米回跳修正了 MTR 飞机的位置插值阈值；最新行程的路线进度没有回退。初到机场仍需等候实际航班到达。

需要恢复到登机梯时，先落地或解除 MTR 乘坐，再使用上面的机场传送指令。不要一边保持乘坐一边不断传送。

UN 基地在第三新东京市的**东北方**，大约 9 千格外：地图上向右是东（X 增大），向上是北（Z 减小）。基地南门为 **6560.5 / 75 / -5968.5**。当前普通 P1／F1 不通往这座远郊基地；快速验收使用已有导航指令：

其他落脚点：

| --- | --- | --- |

| UN 地表机库入口／控制室附近 | `/seele military visit hangar` | 6402.5 / 77 / -6132.5 |

| EVA-UN-00 原泊位 | 需驾驶走回，不是玩家落脚点 | 6442.5 / 77 / -6205.5 |

EVA-UN-00 的“发射”是地表机库排液开门后，驾驶它步行出舱。当前没有 `/seele eva launch un`，`X` 也不会把它送入原三机发射井。

**第一步：在控制室排液。** 不要站在 LCL 池里下令，否则人员联锁会拒绝。持有前面给的身份卡，或处于创造模式。

```mcfunction
/seele military visit hangar
/seele military status
/seele military drain
```

等排液完成；期间可再次查询：

```mcfunction
/seele military status
```

**第二步：状态显示“干燥 / 舱门关闭”后开门。**

```mcfunction
/seele military door
```

等状态变成 **“允许出舱”**，再进入登机栈桥：

```mcfunction
/seele military status
/seele military visit gantry
```

**第三步：登机。** `visit gantry` 默认让你面朝北，先转身朝南／Z 增大的方向，面对背部附近悬挂的黑色识别插入栓舱口，空手右键。它印着 `EVAGELION-UN`。等待自动封舱、低头开背板、吊入、锁定合盖、抬头亮灯完成，再操作。

**第四步：出舱。** 面向南方正门（门所在 Z 约 -6136），按 W 向前走出。不要在吊机仍连接时抢先操作。室外用相同的 W/A/S/D、Ctrl、Space、Shift、Z 测驾驶；**K** 发射 EVA-UN-00 单目激光，瞄准空旷靶区测试。

**第五步：回收。** 自己走回原泊位附近，调整 EVA 朝南、停止移动，按 **V** 申请退出，等待拔栓与退到栈桥。随后离开液舱区域，去控制室，按如下顺序操作：

```mcfunction
/seele military visit hangar
/seele military door
```

等门完全关好、状态回到“干燥 / 舱门关闭”，再注液：

```mcfunction
/seele military fill
/seele military status
```

最终应恢复 **“LCL 保管”**。`door` 是切换键：门开时关门，门关且池干时开门，不要连点；注液要求机体回到原泊位 3 格内且无人驾驶、池内无人。提示“请先关闭舱门”“机体须归位”时，按提示完成前提后再试。

基地墙上的 **DRAIN / GATE / FILL** 三个按钮与这些指令使用同一套联锁。基地坦克、战机和舰炮用各自 Superb Warfare 载具的交互及 HUD；本节的客机步行登舱步骤仅适用于 MTR F1。
