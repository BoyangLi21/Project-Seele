## 驾驶与机库

- 五台机体的右手改用固定的手指关节基准，分别处理放松、握拳、持枪和持刀。重点看手指是否仍扭折，转姿态时是否连续。
- 插入栓完成接入、LCL 排出时转移架升起；新增背部、腰部和小腿支撑。转移架完全升起后接通随架电源并充电。
- 充电接头改为锁紧环、锁扣、护套和短软管，按五台机体实际背甲测量安装位置。地下不再牵一根固定电桩电线穿过整个发射井。
- 到地表后改接发射口南侧新电源，三座桩位为 `-12 81 3`、`30 81 3`、`72 81 3`。旧北侧 `Z=-75` 电桩移除。
- 地下弹射约快五倍：本地图原 **164 tick → 33 tick**。地表收门、18 tick 解除支撑的流程保留。伤害、血量、枪械冷却未改。
- 步枪直接引用已安装 Superb Warfare 的 **NTW-20 第三人称开火音效**，命中烟尘扩大；没有把第三方音频复制进本模组资源。

继续使用电话或现有 EVA 整备、发射、回收指令。驾驶中 **O** 打开电话，**F5** 切换视角；UN 双机指令沿用 R23 手册。

## 第一幕与新增对白

完整操作见 [第一幕逐步攻略](FIRST_ACT_R28_CN.md)：`/seele tv begin` 接受正式剧情，亲自驾驶初号机前往 `356.5 81 -459.5`，近战削弱萨基尔至 32% 以下，在平地站立、保持 14–46 米距离后触发演出。通关后用 `/seele tv status` 核对归档，再正常回收。
