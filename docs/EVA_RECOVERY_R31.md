# R31 受击后的起身

`r31_get_up` 的完整真人录制有 371 个 60 Hz 样本，长约 6.17 秒；中间包含长时间手部支撑和再次降低重心。直接压缩整段，或把仰卧姿势线性混成站姿，都会失去支撑过程。

本轮采用源样本 240–368（2.13 秒）：右手支撑、左脚承重、髋部抬升、站稳。`EvaRecoveryPoseR31` 在普通 64 tick 击倒中保留最初 9 tick 倒地，最后 44 tick 播放这个恢复段并平滑交接；被抛掷落地生成的 46 tick DOWN 直接从已倒地姿势开始，避免落地时先直立一帧。

原录制的 root Y 不直接使用。三台 NERV 与两台 UN 各自按实际身体、脚、掌和手指的支撑包络重求高度；左脚承重时锁住其局部 X/Z。旋转与位移混合之后，重新计算肘、膝实际转轴的补偿，不让关节在过渡中张开。没有缩放骨架或模型，轴辅助骨保留对应机体的 bind。

数据在 `artifacts/facility_r31/recovery/eva_recovery_r31.json`，默认运行位置为 `projectseele-local-maps/eva_recovery_r31.json`；也可使用 `projectseele.recoveryPoseReview` 指定独立文件。`prepare_recovery_r31.py` 生成数据，`check_recovery_blends_r31.py` 检查分数帧。

离线检查包括五套骨架各 840 个四分之一帧，以及新增落地分支各 184 帧。测量支撑包络没有穿过基准地面；肘膝转轴最大误差约 `1.88e-14` 格。基准地面是实体脚部所处的局部平面；斜坡、台阶与最终视觉观感仍由原生地形支撑及游戏检查确认。独立骨架分析图是数值诊断，不是游戏录像。
