## 快速查看

在聊天栏粘贴，例如：

```mcfunction
/execute in projectseele:geofront run tp @s -335 -466 739
/execute in projectseele:geofront run tp @s -28 -461 269
/execute in projectseele:geofront run tp @s -6 -448 385
/execute in projectseele:geofront run tp @s -1480 131 646
/execute in projectseele:geofront run tp @s 328 107 300
/execute in projectseele:geofront run tp @s 13 -389 352
```

火车在站台等开门后，从车门走入；按照原 MTR 乘车方式乘坐。新线路的全部站台、换乘与旧道路接头尚未完成逐点实走，遇到问题请提供坐标。

UN 的新指令已经加入，但本轮中途收尾前尚未完成实机闭环测试：

```mcfunction
/seele military recover 00
/seele military recover 01
/seele military reset 00
/seele military reset 01
```

`recover` 定位原机体并回到原机库，有驾驶员时退出原插入栓；`reset` 将原机体和原插入栓复位并恢复机体血量。不会按找不到实体就生成替代机。UN-01 也支持 `/seele military un01 recover` 和 `/seele military un01 reset`。

汽车充电：

```mcfunction
/give @s superbwarfare:creative_charging_station
```

把创造充电站放在汽车旁，打开它的界面查看充电范围。普通 `superbwarfare:charging_station` 支持食物、燃料或 FE 供电。
