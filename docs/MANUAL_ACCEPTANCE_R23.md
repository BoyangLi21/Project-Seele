## 列车和飞机

地表现在以两条贯通线为主：

- **R1**：雾里住宅区—新箱根—地区技术中心—西部城区—第三新东京中央—湾岸—南部住宅区—箱根湾机场，六节车厢。
- **S1**：新箱根机场—市民广场—新箱根—NERV 地面入口—湾岸—港口，四节车厢。
- 地下 **U1／U2** 和自动航班 **F1／F2** 保留；旧 C1、A1、S2、P1 短线已整合。

列车按原生 60 秒班距运行。发车牌读取实际预计时间，显示北京时间；游戏刚加载时可稍等一次班次同步。换乘使用新箱根和湾岸的直接通道。

等列车停稳、车门与站台门打开后，直接走进车厢，再往里面走两步。到站开门后走出；需要解除跟随时按 Shift。

F2 为 NERV—联合国总部运输航班，每分钟一班；高空巡航限速配置从 300 提高到 **540 km/h**，滑行和进近保留较低速度。它是自动航班，乘客不需要操纵油门。实际客户端已完成约 24.4 公里往返和两端停靠；高速加载区块时仍测到瞬时停顿，最长采样间隔约 3.47 秒。此项通过的是登乘和运行闭环，不能理解为帧率全程稳定。

```mcfunction
# NERV 登机梯下
/execute in projectseele:geofront run tp @s 669.3 73 -1.5
# UN 登机梯下
/execute in projectseele:geofront run tp @s 6712.5 75 -6108.3
```

等停稳开门、登机梯展开，沿梯走入机舱。NERV 侧向北进入，UN 侧向东进入。到站后开门离舱；Shift 可解除乘坐状态。

## UN 双机的出舱与回收

两座机库在地表，直接排液、开门、驾驶出舱。UN-00 床位为 `6442.5 77 -6205.5`，UN-01 为 `6282.5 77 -6205.5`。

UN-00：

```mcfunction
/seele military visit hangar
/seele military drain
/seele military status
# 等“干燥”后：
/seele military door
/seele military visit gantry
```

UN-01：

```mcfunction
/seele military un01 visit control
/seele military un01 drain
/seele military un01 status
# 等“干燥”后：
/seele military un01 door
/seele military un01 visit gantry
```

在登机平台面对插入栓侧面的真实舱口右键进入。等待吊机放入、背板关闭、机体抬头，再驾驶。WASD 移动、Ctrl 奔跑、空格跳跃、Shift 下蹲、Z 趴下；R 切武器，左键攻击／射击，右键重击，G 控制 AT 力场，K 使用眼部激光。

新增回收和复位指令：

```mcfunction
/seele military recover 00
/seele military recover 01
/seele military reset 00
/seele military reset 01
```

`recover` 定位原机体和原插入栓并返回原机库；驾驶中会继续原插入栓退出流程。`reset` 还会恢复朝向和机体生命值。它们保留实体身份，不会生成另一台替代机。离开池内区域后，用对应的 `door` 关门，再用 `fill` 注液。

原三台 NERV EVA 仍使用原命令：

```mcfunction
/seele eva prepare unit01
/seele eva launch unit01
/seele eva recover unit01
```

## 坦克、战机与充电

UN 基地的受管装备从 16 件增加到 160 件；新增 36 辆坦克、27 架战机、9 架攻击机、9 架直升机、9 辆支援车和 54 座防御武器。原装备保留，新增装备已补充能源和弹药。

Superb Warfare 载具操作：空手右键上车，持枪时可用 X 交互；W/S 控制移动或油门，A/D 转向或滚转；左键开火，右键瞄准；数字键／滚轮切武器；Shift＋数字键换座；**左 Alt 离开载具**。飞机使用鼠标控制机头，空格控制起落架，支持的机型可用左 Ctrl 加力。实际改键以游戏设置为准。[模组官方 Wiki](https://github.com/Mercurows/SuperbWarfare/wiki)

自己从物品栏生成的 SBW 车辆可以在附近放充电站：

```mcfunction
/give @s superbwarfare:charging_station
# 创造模式测试可用：
/give @s superbwarfare:creative_charging_station
```

普通充电站接 FE 电源，或按界面放入支持的燃料／食物；创造充电站用于直接测试。基地自动能源供应针对已登记的基地装备，自己新刷的车请使用充电站。
