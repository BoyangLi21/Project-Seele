# 指挥室电梯恢复（2026-09-06）

## 实测原因

指挥室后侧电梯轴为 `(12, *, 253)`，现存停靠层是
`-566 / -448 / -423 / -419 / -409`，控制器在 `(9, *, 253)`。
Moving Elevators 1.4.12 的捕获范围为 5×6×5；桥层与后勤层只差 4 格。
依赖的 `ElevatorCage.canCreateCage` 只要求范围里至少存在一个可移动方块，
不要求有底板。轿厢实际在 -419 时，-423 的捕获范围也包含它的下两层。
外部召梯按距目的地远近查找候选，因而会从 -423 截走这两层。

用户预览会话的日志已保存为
`artifacts/command_lift_recovery_20260906/user_session_20260905_2336.log.gz`
（游戏的滚动日志文件名会随启动变化），其中显示：

- 23:36:37 在 -419 接管现存轿厢。
- 23:37:10 报 `(10,-445,251)` 的 Polished Deepslate 阻挡轿厢。
- 离线逐格检查发现：原 -420 底板被移到 -445，-419 墙体被移到 -444，
  上方墙体、面板和顶板仍留在原位。偏移恰为 -448 减 -423，即 -25。
- R28 底板仍完整，但能力存档把 -423 与 -419 都记录为有轿厢。

## 修复

`MovingElevatorGroupAccessMixin` 在依赖的可用性计算内，对这一个 GeoFront
电梯组增加完整 polished-deepslate 底板检查。依赖原有的方块合法性、
可用性缓存、客户端同步和真实平滑运输继续生效；其他电梯组不受影响。
因此外部按钮、轿厢楼层选择和原生上下按钮都不会选择半台轿厢。

`tools/repair_command_lift_split.py` 恢复这次预览中的特定损坏：

- 以 R28 现存完整轿厢为参考，只改井内 84 个实测差异方块。
- 差异数量和 SHA-256 必须匹配本次事件，否则拒绝修改。
- 写入前备份实际目标的 region 与 capabilities，导出正向、反向逐格补丁。
- 不搬运其他世界的整份 region，不改楼层位置、房间、控制器或旧运行状态。
- 写后通过 `query_blocks.py` 验证整个被测井内范围与健康参考一致。

Minecraft 关闭时执行；默认只出计划，`--apply` 才写入：

```powershell
python tools/repair_command_lift_split.py --world SEELE_PYRAMID_TV_PREVIEW_20260905 --apply
```

## 可重复的实际运行验证

`CommandLiftReview` 必须显式传 `-PcommandLiftReview`，且只允许两个指定测试
副本 `SEELE_LIFT_REVIEW_R28_20260906` / `SEELE_LIFT_REVIEW_PREVIEW_20260906`。
它拒绝在 R28 或交给用户的预览上运行。

测试先直接证实原生 -423 检查会产生假阳性，再验证修复后只认 -419。
通过真实模组调用进行七段行程：

`-419 → -448 → -423 → -419 → -409 → -448 → -566 → -419`

首段使用外部召梯，其余通过轿厢楼层选择。每段检查真实移动、到站唯一
轿厢、141 个非门控方块的完整运输、面板随车、乘客高度和整条出口的
玩家碰撞净空。另检查受限层无卡拒绝、有卡进入及同层召梯不会重新捕获。
保存退出后可原命令重跑以验证重新载入。

```powershell
./gradlew.bat --offline runClient -PquickPlayWorld=SEELE_LIFT_REVIEW_R28_20260906 -PcommandLiftReview
```

实际结果：R28 副本、修复预览副本、保存退出后的预览重进均完成全部七段，
共 **21 段通过**。两个测试存档的持久化能力均只将 -419 标记为有轿厢。
最终 `gradlew --offline build` 通过。日志中 MTR 货运装卸方块的两项 loot table
解析错误也存在于用户修复前会话，与本次电梯修复无关。

本地证据和备份：`artifacts/command_lift_recovery_20260906/`，含 `validation.json`、
三次成功运行日志、修复前状态、84 格正反补丁及正式预览的原 region 备份。
测试副本收存于其 `test_worlds/` 子目录；重跑前将需要的副本复制回 `run/saves/`
同名目录，保持正式 R28 与用户预览的角色不变。
最终人工验收：在原 R28 或 TV 金字塔预览中，先从下层召梯，再乘到指挥桥、
后勤层和上层画廊，确认门打开后可以正常走出。
