两艘舰分别位于 X=1444、1494，Z=330..567；船体不移动。Z=420 的登舰桥、中央指状码头与南侧连接栈桥均有真实通行路线。现代舰炮和近防武器移到岸防位置，原有 AH-6 移到 X=1306、Z=546 的岸上直升机坪，所有原受管实体 UUID 和防御控制节点保持原有身份。

港区补充甲板高差连接、排水与警示线、货柜端门、可进入货柜、仓库中央通道、维修用品与吊机。吊机的斜撑和索具使用本项目的原生展示构件，保存在独立 R08 SavedData 中；它们是固定景观构件，吊机不冒称为可操作机械。没有把 SBW 载具模型拆出再发布。

基地新增指挥、简报、分析等房间，指挥厅调整为三排共 42 个操作位；坦克维修区有独立作业线、工具及维修台、桥式吊机。飞机库改为中央出机空间与两侧玻璃维修间，增加工作台、工具、器材和屋面结构。宿舍、建筑立面、设备屋面、服务院落与外围墙体亦增加细节。

## EVA 移动与试验机

普通机体不再被近脚部的小型地面饰物顶起；完整墙体、楼梯、半砖、门、舱门 barrier 和脚手架继续保留碰撞。脚部贴地计算使用同一过滤规则，避免视觉上的脚跟被灯笼、栏杆等抬起。

跳跃改为单次服务端授权、骑乘客户端执行。旧的通用速度包会在授权前后以不同顺序到达，并把速度截到 3.9，造成一次跳跃被重复推动或中途压低；现已消除这一竞争。站立、行进和重击中转起跳均通过真实键盘输入实测。起跳、着陆动画加速，移动着陆保留步态相位。

| 参数／行为 | 之前 | R08 |
|---|---|---|
| 起跳速度 | 3.49 格/tick | 4.836 格/tick |
| 重力属性 | 0.08 | 0.18 |
| 原生阻尼递推的典型飞行时间 | 约 65 tick | 约 44 tick |
| 原生阻尼递推的典型高度 | 约 37.58 格 | 约 40.27 格 |
| EVA 坠落扣血 | 存在高度门槛后的伤害 | 不再造成坠落伤害 |
| 机体受伤转给驾驶员 | 同步率较高时存在比例传递 | 取消 HP 传递 |

真实测试观察到三次最高点约 40.13、40.27、40.27 格，包含网络授权等待的服务端计时为 45、52、53 tick，机体和驾驶员落地后血量均保持。其它武器伤害、机体总血量和攻击冷却未在本轮调整。

试验机按已认可设计图重新建立头部、肩甲、胸腹、四肢和关节，采用黑色／深灰装甲与金色细部。网格为 98,722 个三角形、46 个部件，保持 70 骨接口及独立试验机身份。地表试验机库开放后仍提供机体展示照明，避免从保管转为可驾驶时突然变成黑色剪影。该模型是按图手工重建的近似造型，不能把几何数量当作设计图吻合程度的证明。

实景还确认了大型实体近景消失问题：原版在实体通过视野检查之后，又要求其脚下区段的地形网格已编译。只看 EVA 头部时，脚下区段可能不满足这一条件，整台机体就被跳过。R08 对 EVA 和长工程构件保留完整的视野／距离检查，改用已加载区块作为该额外门槛；相同高位近景现已能显示头部与躯干。实际绘制头部位置约 `(6442.5, 130.411, -6203.205)`，与保存的机体位置吻合，没有靠移动模型来掩盖问题。
