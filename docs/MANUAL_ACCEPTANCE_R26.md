# R26 现场修正与操作

本地启动 `start_eva_test_r26.bat`，仍使用 `SEELE_TV_WORLD_PREVIEW_20260906`。联网时客户端和服务器都用 R26 包；本轮同步数据协议升为 32，不能混用 R25 客户端。

## 通路与标牌

- 东侧直梯移到金字塔内部，中心 **X=66、Z=302**，南侧进出。停靠 **-461、-448、-434、-420、-406、-392、-378、-364** 八层，不进入 Terminal Dogma。每层入口都接入本层走廊，上部接廊绕开原折返楼梯。
- 从房间出来看“楼层导引”；跨层会先指向直梯，并标目标楼层。仍可使用 `/nerv route command` 等动态引导。
- 原有站序图按实际站台和列车出站路径改方向；站台中部新增站序图，房间出口和电梯口增加导向牌。总部交通接驳处设置 **NERV TOKYO-3** 大牌。
- 三个发射井外侧形成连续黑色围护；保留接入封闭机械通道和观察室的必要内部门口。`92 -362 -52` 的顶缝封闭，`-56 -443 220` 外侧旧台面退休。
- `-28 -394 -267` 附近的残缺步道改成平整交叉口。仍正常连接楼层的原扶梯保留。

## 人员与电话

普通右键 NPC 只在左下聊天栏显示岗位台词。命令和联系人在电话里：携带员工卡与卫星电话，右键电话；驾驶 EVA 时也可以按 **O**，HUD 显示当前通信按键。若改过键位，以“指挥通信”绑定为准。

```mcfunction
/give @s projectseele:nerv_employee_card
/give @s projectseele:satellite_phone
```

电话“指挥”页新增 **下机返回待命**：先完成回收、确认机体在机库停稳，再通知对应驾驶员离开插入栓。出动或转移中的机体会拒绝此操作。美里／冬月／律子的岗位权限继续生效，警卫不能发射。

指挥室原拼装凳子、椅背和装饰替换成完整座椅，座位位置保留；工作人员寻路绕开椅子及椅面。

## 机库与电源

吊机及轨道降低 9 格；固定支撑架保持开放顶部，移除上方横栏。插入栓动作时，转移架留在地下；锁定插入栓后，随 LCL 排出升起。回收时先固定机体、降下转移架，再抽出插入栓。地表舱门完全关闭、形成支撑之后，EVA 脚下的转移平台才结束显示。

地下使用 **五分钟内置电源（6000 tick）**，完整接入后开始计时，不再自动接地下电缆。到地表后接入地面接口；距离仍为 768 格。电缆先从背部向后引出，再绕过机体。超过距离或本体受伤仍会断线；伤害、血量和武器冷却没有调整。

重点验收：八层电梯的出入口、上层楼梯交叉处、站牌箭头是否随观察方向和列车方向一致、NPC 右键与 O 键、下机待命，以及整备→发射→关门→回收完整流程。

UN 双机、坦克、飞机、列车与充电操作继续见 `MANUAL_ACCEPTANCE_R23.md`。写实材质沿用 rotrBLOCKS 128×，新客户端运行 `Install-Textures.bat` 从作者官方源获取。
