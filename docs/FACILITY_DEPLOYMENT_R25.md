# R25 通路、驾驶与部署

本轮继续使用 `SEELE_TV_WORLD_PREVIEW_20260906`，修改先在 `SEELE_R25_REVIEW` 验证，再按逐格补丁安装。没有整份测试世界覆盖正式存档。

## 设施

西侧四层与东侧四层接入指挥室联络廊；新增东侧五停层电梯及西侧观察廊两停层电梯。三个外部死路分别接到保留的下层通道、相邻房间与实际庭园地面。下层失效长廊退役，机库站西侧接驳贯通，观察廊遮挡板拆除。科研区上层桥与下层楼梯分别保留，避免新楼梯破坏旧桥。

1,076 个平面自动步道端部按水平模型修复，252 个真正斜梯端部保留。全线增加 44 块原生站序图和换乘箭头；方向牌使用箭头，23 块新小标牌抬至人物净空之外。短线路站序图加大字号，长线路按板面高度适配，文字下缘留在黑色屏幕内。文字与真实 MTR 线路／站台 ID 对应。

额外检查发现新接廊封堵旧主路、新站序图支柱挡路等交叉问题，均修复后重测。金字塔东侧旧电梯接口外壳封闭，保留原 7×7 轿厢、控制器与全高井道。正式安装范围、逆向补丁和保护数据校验存于本地 `artifacts/facility_r25/promotion/`。

## 操作与动作

卫星电话及 O 键提供关键人员通信；命令按岗位在服务端校验。美里／冬月指挥，律子整备和回收，伊吹查询，警卫不能发射。驾驶员改用绫波丽、碇真嗣、惣流·明日香，可实际走到原插入栓登机；登机本身不触发发射。三名驾驶员和原有 NPC 不重新生成。

趴姿禁跳并清空缓冲跳跃；趴姿瞄准角和身体转向连续过渡。原三机增加姿态相关的后颈关节与肩塔避让，蹲行双腿保留原动作时序并加宽支撑。瞄准、武器射线和第一人称沿用同一姿态数据。控制架上方横梁让出插入栓真实扫掠空间。

供电距离默认 **32→768**；背部接头随最终身体姿态，电缆使用不发光的圆形截面和圆滑转角。保存并保持原电源锚点，地表三个缺少方块实体的接口补齐；升至地表后转交地表卷线器。实际扣本体血量或超距离后断电；AT 力场完全挡住的命中不切线。步枪音量 **3.2→4.2**，采用原创机械冲击音；伤害、血量、射速与冷却未变。

## 材质与交付

选择 [rotrBLOCKS](https://modrinth.com/resourcepack/rotrblocks) V87、128×、2D Foliage，EVA 专用资源优先。1.20.1 不识别作者的新式多版本声明，安装器因此同时记录已接受的资源包版本，避免启动时自动取消。原 ZIP 不修改、不重分发；客户端直接从作者官方 CDN 下载并验证散列。没有默认开启光影或旧的透视 LOD。

`tools/package_release_r25.py` 构建服务器、完整存档、客户端三个独立 ZIP；`tools/test_packaged_server_r25.py` 在一次性目录运行正式 Forge 与混淆后 JAR，再检查 GeoFront 数据与正常保存。各包的实际结果及散列以交付目录 `artifacts/server-ready-r25/RELEASE.json` 为准。操作入口见 [R25 手册](MANUAL_ACCEPTANCE_R25.md)，部署步骤见 [服务器部署](PRIVATE_SERVER_DEPLOYMENT_CN.md)。
