# R31：动作、战斗与回收

基线是负责人 2026-09-23 确认的 R30 本地存档。先保留最新玩家／任务／交通进度，地图施工在独立副本进行；上轮测试存档不作为正式地图源。

本轮重点是可玩的战斗循环：可识别的起手与收招、连续输入、跳击与下砸、双方实际位移和受击状态、双手抓取及投掷。抓取必须经过接近和接触，不直接吸附模型；投掷后受原生重力与地形碰撞影响。保留枪械和 AT 力场的作用，避免靠无限震屏或任意伤害倍率伪装手感。

并行处理 UN 两库净宽、reset 骨骼与插入栓同步、废弃落地插入栓可摧毁、EVA 横置运输及翻转载台、地面转移架与飞行货架分离。继续修改 UN 装甲细节，不靠压缩机体尺寸来回避机库问题。NERV 电缆接头按实测红色背部接口上移；先禁用存在严重问题的零号机自动蹲盾。

角色对白保持纯文字，按 TV 时期性格和指挥权限重写。设施及交通广播可以保留，但与人物发言区分，减少重叠和生硬的系统说明。

研究来源逐项记录于本轮设计笔记。成熟游戏的开发者讲解用于设计参考；现有动捕、可合法使用的动作资源用于重定向。社区插件推荐只作为线索，实际能力与维护来源需核实。既有本地 Blender API 已能完成网格、骨骼和材质编辑，不将安装插件等同于质量提升。

该文件是实施清单，不是完成声明。每项实现、已有检查和未完成验收分别记录；不能以“AAA”称谓替代可见效果与可操作反馈。
