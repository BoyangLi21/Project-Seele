# R31 接触、受击与恢复

这一批围绕实际接触重新组织战斗。新增空中左键下击、空中右键落地砸击、空手双手抓取与投掷；普通地面攻击及枪械原有伤害不变。三个新增动作基础伤害均为 35，实际扣血仍经过原护甲和 AT 结算。萨基尔高于 270 点 AT 时不能抓取。默认抓投键为逗号，避免与已安装的小地图设置和拖曳解除键冲突。

抓取先由 EVA 走到可够及的位置，手掌渐进贴到实际使徒网格上的接触点；使徒不会在按键时瞬移到手里。肩、肘、腕按各机体骨架长度求解。抓稳后抬起，投掷第 16/26 tick 释放，此后的移动遵循碰撞和重力。接触表只支持已测量的萨基尔、夏姆榭尔，不以宽大的包围盒假定所有使徒都适用。

空中拳击按手端的连续扫掠判定。Minecraft 的实体空间索引以实体脚部所在区段登记，只搜索高处拳头附近会漏掉身高约 60 格的使徒；这里扩大了候选范围，仍保留实际线段与身体的接触和墙体遮挡检查，没有改成范围内自动命中。落地砸击是单独的近地冲击范围。

受击分为轻颤、短暂失衡、倒地和抛出。重击可以打断当前进攻，双方有短暂命中停顿、方向性身体后摆、实际位移和落地碎屑。一次普通命中不会每帧重启倒地。关机姿势与战斗倒地分开；临时倒地可通过手撑、落脚和抬髋动作恢复，损毁机体继续等待回收。

真人素材与重定向见 [动作来源](COMBAT_CAPTURE_R31.md)。起身采用 GettingUp 的连续手撑至站起段，而非整段包含重复倒地的原始录像；五套机体分别保留骨长、关节中心和脚底支撑，混合时重新计算肘膝补偿。这里没有缩放模型来伪造接触，也没有实现全身物理布娃娃。

客户端与服务端的实体对象虽然不同，Minecraft 仍会按相同网络 ID 判为相等。本轮把共用战斗状态和冲量表改为弱 identity 键，避免本地服务器中客户端状态覆盖服务端状态、或同一次命中重复加入冲量。独立检查包含相同 ID 的两对象隔离、清除互不影响和弱引用回收。

## 实测边界

在独立 R31 副本、真实客户端输入下，初号机对萨基尔的前后移动、跳击、落地砸击、抓取、抬起、投掷落地和两次来袭攻击均完成。跳击与砸击各造成 32.2 实际伤害；抓取抬高 6 格，投掷位移约 75.34 格；来袭攻击累计扣除 EVA 84 点生命并产生后退、倒地和恢复。最后一次录像运行的 227 个满接触权重手掌样本中，最大目标误差约 0.0023 格。过渡阶段仍保留完整记录，不将接近中的手掌当作已经接触。

此记录不等于所有地形、全部机型或专用服务器都已验收，也不以数值通过宣称达到商业游戏的动作制作水平。最后一次测试图、逐帧证据和 `R31_native_combat_silent.mp4` 位于本地 `artifacts/facility_r31/native_combat_1790138167321/`。视频使用 378 帧真实游戏画面，按采集时间编码，没有补画中间帧，也没有录制音频。连续观感与操控体验仍需人工验收。
