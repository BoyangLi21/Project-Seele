# R30：第一幕与驾驶员出战

本轮可选择并重玩「萨基尔」和「夏姆榭尔」。完成记录保留；后续 TV 章节仍是待开发档案。第一幕包含出击、真实战斗和初号机收尾演出，不包含第 1—2 话的所有生活场景。

## 开始前

客户端、服务端、存档使用同批 R30。先进入 `SEELE_R30_WORLD`。管理员可取得通信用品：

```mcfunction
/give @s projectseele:nerv_employee_card
/give @s projectseele:satellite_phone
/seele tv status
```

手持 NERV 卫星电话右键；驾驶时按 **O** 打开通信。先联系冬月下令城市沉降，等中央可升降区域完全收纳。战区中心约为 **32.5 81 195.5**。该区域的楼群未降到底时，任务会等待。

## 让真嗣驾驶初号机

1. 电话联系美里，打开「作战记录」。
2. 选择「萨基尔」和「初号机」。
3. 选择「碇真嗣出战」。可选择「先前往武器井取枪」或「近战出击」。
4. 点击「下达迎击指令」。约九秒通信简报依次报告异常波形、蓝色目标、战斗配置和连接检查；指挥室、机库响警报并闪红灯。
5. 等真嗣到机库、进入原插入栓。美里会操作真实控制台，依次整备与发射。不要在中途反复下达同一指令。
6. 初号机到达地表后，驾驶员前往已部署的武器井领取步枪，再驶向战区；近战出击则直接迎击。他会换用射击、近战和力场，实际伤害决定战况。
7. 萨基尔残血后，初号机会结束当前攻击并调整距离，条件满足时进入首战收尾演出。NPC 仍是原来的真嗣；司令不会被强制塞进驾驶舱。

想按 TV 第一战看完整收尾，请用**初号机对萨基尔**。其他机体可以参加实际战斗，但不会套用初号机专属收尾演出。夏姆榭尔采用自身战斗结束流程。

## 亲自驾驶

在同一页选「亲自驾驶」，然后下达迎击指令。若 NPC 已坐在目标机内，先在通信页让该驾驶员「下机返回待命」。

通过 `/nerv route hangars` 前往机库。初号机登机廊在 **30.5 -394 -267.5**；空手对准原插入栓舱口右键登机。坐稳后按 **O** 联系美里，下令「整备后发射」。也可由管理员分步测试：

```mcfunction
/seele eva prepare unit01
/seele eva status unit01
```

等状态变成 `SILO_READY`，再执行：

```mcfunction
/seele eva launch unit01
```

等地表舱门关闭、支撑解除后再行走。从初号机井口 **30.5 81 -35.5** 向 **+Z（南）** 前往中央战区。不要用玩家传送命令替代驾驶整机移动。

| 默认按键 | 功能 |
| --- | --- |
| WASD / Ctrl | 移动 / 奔跑 |
| 空格 / Shift / Z | 跳跃 / 下蹲 / 趴下切换 |
| R | 切换已装备武器 |
| 左键 / 右键 | 普通攻击或射击 / 近战重击 |
| G | AT 力场 |
| O / F5 | 指挥通信 / 视角 |

以游戏按键设置为准。趴姿不能直接跳起。步枪不能绕过仍完整的使徒 AT 力场；近战和力场中和后再攻击本体。不要另行召唤使徒替代任务生成的目标。

## 通关、回收和重玩

战斗结束后用 `/seele tv status` 查看记录。选择重玩不会清空已完成章节。也可先选择章节，再使用常规开始命令：

```mcfunction
/seele tv select sachiel
/seele tv begin
```

第二章选择命令为 `/seele tv select shamshel`。NPC 或亲自驾驶的选择请使用电话界面。

机体还能行动时，按原流程回到发射井并联系指挥室回收。机体损坏、驾驶员弹出或电源耗尽时，电话进入「运输部门」，选择机体，点「空运回原发射井」。运输机将原机体送到对应地表井口后等待；再下达常规「回收」，才会下降并送回机库。空运过程中需保持上方净空。

回到机库后步枪会归还，不会无条件带入下一次出击。选择另一场任务前，先撤销尚未结束的当前作战，并让目标机恢复待命。
