# R31.1 普通攻击回归修复

负责人明确拒绝了 R31 的普通攻击和整体战斗体验。此前的跳击、抓投流程记录不能代表普通攻击已经检查，更不能代表动作质量达到预期。本次先修复可复现的退步，整体战斗美术与手感仍未获得人工认可。

## 确定的根因

原有普通攻击带有真实水平位移。Minecraft 在这次没有 Y 位移的碰撞计算之后，会暂时把 `onGround` 清为 false。R31 新加的空中攻击入口只检查这个瞬时标记，于是连续左键会取消正在播放的地面连段，改播空中下击和落地动作。玩家没有跳，机体也一直留在地面，却被反复接管并锁住移动。

修前在初号机平地重复输入中，空挥、命中、移动攻击分别出现 80、68、67 tick 的错误空中／落地状态。重击单项没有复现相同错误。它不是玩家操作问题，也不是渲染设置造成的。

修正包括：

- 空中攻击必须同时具备已确认的跳跃／坠落状态，不能仅凭瞬时 `onGround=false` 接管。
- 原有攻击的水平位移后，只在脚下仍有真实碰撞支撑时保留落地状态。走出平台不会被强行悬停。
- 新动作的姿势混合、落地附加旋转后，重新计算膝肘转轴补偿，避免旋转与平移分开混合时关节被拉开。

伤害、血量和冷却沿用 R31，没有用改变战斗数值掩盖这个问题。

## 检查范围

对零号机、初号机、二号机、UN-00、UN-01 分别使用实际客户端输入，检查空挥连段、命中连段、地面右键和移动中连击。修后五台均未触发错误空中状态；已查看各机型的实际录制帧。另检查真正跳跃后的攻击、抓投和受击恢复继续工作。

这些是针对本次回归的检查，不构成全地形、所有组合或主观战斗质量的通过声明。当前画面和原始状态记录位于本机 `artifacts/combat_repair_r32/` 及报告指向的录制目录。

## 使用

本机开发入口继续使用根目录 `start_eva_test_r31.bat`，打开现有 `SEELE_R31_WORLD`，保留刚产生的游玩进度。

PCL 或已准备好的独立客户端／服务器，退出游戏后，把修复 ZIP 解压到该游戏目录，覆盖 `mods/projectseele-0.1.0.jar`。客户端和服务器都应更新这一个模组，网络协议保持 35。存档、R31 模型资源包、材质和光影继续沿用。

旧 R31 五包中的模组需要叠加本补丁。普通攻击回归已修复；整体战斗体验仍按未通过验收处理。
