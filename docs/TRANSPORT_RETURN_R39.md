# R39：运输、战后返航和室内光影

本批使用 Minecraft 1.20.1、Forge 47.4.10、Java 17，通信协议 **44**。客户端和服务端应使用同一批文件。正式存档继续使用 `SEELE_R31_WORLD`，保留 2026-09-25 晚间的人工试玩进度。本轮不施工地图，不改血量、伤害或模型资源。

## 变化

- UN 运输坐标每 **10 秒现实时间**汇报一次。阶段变化和加载等待保留在状态查询内，不再逐条刷聊天。
- 起吊先垂直离地，再翻转为横向运输，避免在脚部尚接地时转动鞍座。
- NERV／UN 长途飞行名义速度由每 tick 20 格提高到 60 格；保留起降过程。前方分批预加载，等待区块时暂停在当前进度，不再反复从零启动整段加速。载荷的客户端位置跟随服务器实际进度。
- AI 作战结束后，机体在本机舱口 640 格范围内且能行走时自行返航；距离过远、失去动力或持续受阻时，由驾驶员发文字请求，由 NERV 运输部门排队接回。玩家驾驶的机体不会被自动接管。
- 返航记录独立保存，支持多台 NPC 机体。重新分配出击任务会取消该机的未执行返航；运输仍遵守原实体、原插入栓和驾驶员的绑定。
- 普通回收与运输交付使用相同顺序：**支撑架用 100 tick（正常 20 TPS 下为 5 秒）升起 → 舱门逐层打开 → 确认实际舱门开启及封口撤除 → 下降回库**。支撑架和底盘有升起过程。运输夹具先离开，再开始回收机械。
- 光影沿用 Complementary Unbound 5.3 的 LCL 兼容版本，改进室内间接光。光影设置首页新增「SEELE 室内补光」，默认 140，可选 80–180。真实灯具、阴影与总指挥席后的照明拉杆仍有效。
- 派遣状态改为按每次出击单独记录，处理上一趟驾驶员遗留“已连接”状态造成下次漏派的问题。

640 格是自动决定步行或空运的界限；近距离道路受阻后也会请求空运。长途飞行的实际耗时仍受服务器 TPS、磁盘和未生成区块影响。受阻不会穿过建筑强行运输。

## 台词与人物情境

三个驾驶员的台词分别处理待命、登机、战斗、返航、空运和下机。删除索要战斗记录等不合身份的台词，减少无缘由的挑衅、反复喊口号和凭空汇报故障；回库后的步行不再播成登机。自动返航的三种通知也使用各自的角色台词，保持纯文字。

本批对白是原创改写，不标作原作逐字台词。参照 TV 版人物和事件关系；资料入口为[关西电视台的 TV 版分集简介](https://www.ktv.jp/evangelion/)。具体口吻仍以人工试玩反馈修订。

## 五个包

1. `Project_SEELE_R39_Client.zip`：直接拖入 PCL 安装新的独立实例。已内置模组、模型、最新存档、材质和光影，无需再运行下载素材的脚本。PCL 只可能补齐缺失的 Minecraft／Forge 基础运行库。建议给客户端分配 6–8 GB 内存。
2. `Project_SEELE_R39_Server.zip`：服务端模组、配置、运行资料及 Forge 运行库。解压后，将存档包内容放到其中的 `SEELE_R31_WORLD` 文件夹。阅读 Minecraft EULA 后自行将 `eula.txt` 改为 `eula=true`，使用 Java 17 运行 `Start-Server.bat`。控制台用 `whitelist add 玩家名` 加入白名单，需要管理权限时再用 `op 玩家名`。
3. `Project_SEELE_R39_World.zip`：解压后根目录即为存档内容，含 `level.dat`。手动安装时放入 `saves/SEELE_R31_WORLD`；服务器放入同名目录。
4. `Project_SEELE_R39_Shaders.zip`：独立光影备份，合并到实例目录。客户端包已经包含。
5. `Project_SEELE_R39_Textures.zip`：独立材质备份，合并到实例目录。客户端包已经包含。

本机开发入口为 `start_eva_test_r39.bat`。可加 `--no-shaders` 临时关闭光影；默认选择 R39 光影。旧存档和旧包保留。

## 人工检查

先通过电话向 UN 运输部门发一个长途投放请求，观察聊天坐标是否按十秒间隔出现。再进行一次 NPC 作战：检查结束后是否自行返航或发出运输请求。可以加另一名驾驶员支援，确认两机分别回到各自机库。

站在地面发射口附近查看回收：支撑架应逐渐升起，升至顶端后才开门，机体随后下降。手动请求回收和运输机送回两条路径都应如此。

打开光影设置，确认选择 `ComplementaryUnbound_r5.3_SEELE_R39.zip`。看指挥室、金字塔内部和转移通道的墙面、天花板与远端出口；切换总指挥席后的照明拉杆，灯具应仍能开关。

NERV 运输维护命令保留：

```mcfunction
/nerv transport status
/nerv transport force_recover
```

`force_recover` 是管理员维护操作：让原服务飞机返回机场，实际载荷交付原机体的地面舱口。常规使用优先电话运输与普通回收。

第一幕的选章、编队与出击操作见同包《第一幕流程.md》。本轮改变返航和回收，不宣称完成了新的战斗动作或模型美术。
