# R31 第一幕操作

当前可选择并重玩「萨基尔」和「夏姆榭尔」。已有完成记录会保留，后续 TV 章节仍是待开发内容。首战包含迎击简报、登机发射、实际战斗和初号机收尾演出，不代表第 1—2 话全部生活场景都已完成。

## 准备

进入同批 `SEELE_R31_WORLD`，取得员工卡与 NERV 电话：

```mcfunction
/give @s projectseele:nerv_employee_card
/give @s projectseele:satellite_phone
/seele tv status
```

手持电话右键打开通信；驾驶中按 O。先联系冬月，选择「城市」并降下城市。等中央升降区域完成收纳。管理员也可输入：

```mcfunction
/seele tokyo3 retract
/seele tokyo3 status
```

迎击区中心约为 `32.5 81 195.5`。城市尚未准备好时，任务会等待，不要在交战中升起楼群。

## 让真嗣出战

1. 电话联系美里，打开「作战记录」。
2. 选「萨基尔」「初号机」「碇真嗣出战」。可选先去武器井取枪，或直接近战。
3. 下达迎击指令。先有异常反应、目标识别和出击准备的文字通信；指挥室、机库有警示灯与设施广播，角色本身不配语音。
4. 等真嗣走到机库、进入原插入栓。美里操作控制台，完成整备和发射；无需连续重复下令。
5. 初号机抵达地表后，按所选方案取枪、前往目标并实际交战。
6. 萨基尔残血、距离与场地满足条件时，进入初号机专属收尾演出。玩家仍在司令位置，不会被强制塞入驾驶舱。

首战收尾使用**初号机对萨基尔**的组合。选择别的机体仍能战斗，但不会套用这段专属演出；夏姆榭尔使用自己的结束流程。

## 亲自驾驶

在同一作战页选择「亲自驾驶」。若 NPC 已在该机内，先用电话让驾驶员「下机返回待命」。

```mcfunction
/nerv route hangars
```

沿引导进入初号机登机廊，参考落脚点 `30.5 -394 -267.5`。空手对准原插入栓舱口右键上机。坐稳后按 O 联系美里，选「整备后发射」，或管理员分步执行：

```mcfunction
/seele eva prepare unit01
/seele eva status unit01
```

等到 `SILO_READY`，再发射：

```mcfunction
/seele eva launch unit01
```

等地表舱门关闭、支撑解除。从初号机井口 `30.5 81 -35.5` 向 +Z 前往中央迎击区。不要用玩家传送代替整机驾驶。

WASD 行走、Ctrl 奔跑、空格跳、Shift 蹲、Z 趴。左键普通攻击，右键重击，R 切换武器，G 开关力场。先近战削弱使徒力场，再攻击本体。步枪不会无条件穿过完整 AT 力场。

R31 可以在空中左键跳击、右键下砸；站立空手、靠近并正对可抓取使徒时按逗号键 `,`，抓住后再按逗号或左键投掷。力场未削弱、距离不足或剧情演出中，抓取不会执行。详细体验检查见 `MANUAL_ACCEPTANCE_R31.md`。

要看首战收尾，将萨基尔本体血量打到 32% 以下，然后结束当前动作、恢复站立，保持约 14–46 米距离，给两者留出平整空间。系统随后接管专属演出；演出中不要反复发射、复位或运输同一机体。

## 归档与回收

```mcfunction
/seele tv status
```

任务记录确认完成以后，返回初号机地表回收平台并停稳，联系美里回收：

```mcfunction
/seele eva recover unit01
```

机体损坏、无人或电力耗尽时，可通过 NERV 电话「运输部门」空运回原井顶。飞机接地释放后，再执行常规回收，不能直接从地表穿过设施外壳送入机库。

回库后步枪归还；下一次出击要重新领取。需要重玩时，在电话作战记录中重新选择，也可以使用：

```mcfunction
/seele tv select sachiel
/seele tv begin
```

第二章为 `/seele tv select shamshel`。若已有尚未结束的作战，先在电话中取消当前作战，再安排下一次。NPC 与亲自驾驶的选择通过电话完成，普通开始命令不会替代驾驶员安排。
