## 坦克与战机

当前安装的是 Superb Warfare 0.8.9.1；最终实际键位以本轮客户端导出的 `actual_vehicle_keybindings.json` 为准。

| 操作 | 默认按键 |
| --- | --- |
| 上车 | 空手靠近并右键；持枪时用 `X` 交互 |
| 坦克移动 | `W/S` 前进／后退，`A/D` 转向，空格刹车 |
| 战机油门 | `W/S` 增加／减少油门 |
| 战机操纵 | 鼠标控制机头，`A/D` 滚转；空格控制起落架；左 Ctrl 加力（机型支持时） |
| 开火／瞄准 | 左键开火，右键瞄准 |
| 武器选择 | 数字键或滚轮；可用武器依当前座位而定 |
| 换座位 | 按住 Shift，再按数字键 |
| 离开载具 | **左 Alt** |

官方说明确认了左键开火、滚轮／数字键选载具武器、Shift＋数字键换座以及左 Alt 离车；飞机细项另外按本机模组键位核对。[Superb Warfare 官方 Wiki](https://github.com/Mercurows/SuperbWarfare/wiki)

已有基地载具在 UN 基地的机坪与车库；新 NERV 机场已放置两架 AC-130H 和两架 J-16。可驾驶的 SBW 载具与自动运输航班分别使用各自的乘坐方式。F2 停稳、开门、登机梯展开后，正常走进机舱即可，不需要自己操纵航班油门。MTR 列车、航班停稳后按住 Shift 离开；SBW 坦克、战机使用左 Alt。

## 金字塔内的路线指引

北侧换乘厅的大牌指向北联络廊与发射区车站，身后楼梯返回大指挥室。机库电梯依次连接联络层、登机层和观察层；观察层东端大牌分别指向正面观察窗、后侧贯通观察廊和返回电梯的方向。本部南侧公共通廊的牌子连接指挥区与科研联络桥。

长走廊提供双向自动步道和普通步行带。导向板位于固定墙面，不安装在会收回的电梯门上。车站发车板继续显示真实运营信息。

## EVA 与机库声光

使用现有 `/seele eva prepare unit01`、`/seele eva launch unit01`、`/seele eva recover unit01` 完成一次真实机械循环。检查插栓、锁闭、排液、轨道运转、中文播报、三秒倒计时、弹射声、红色警灯及回收提示。

播报已换成较自然的中文神经语音，警报使用音量更低的短促双鸣。声音全部预先保存到本地，游戏运行时不需要联网生成语音。

地面行走和攻击时，驾驶舱中应能听到脚步、空挥、命中和步枪声；传播距离已单独按 EVA 的机体尺度处理，普通手持步枪保持原声音范围。

两个 UN 机库的舱门内外均应读作 UN，不能出现 NERV 字样或反向文字。

## 两台 UN 机体

UN 总部在城市东北方很远处（X 为正、Z 为负）。两个试验舱并排：UN-00 床位 `6442.5 77 -6205.5`，UN-01 床位 `6282.5 77 -6205.5`。两台是独立身份、独立插入栓；不占用 NERV 原三机名额。

**UN-00 出舱顺序：**

```mcfunction
/seele military visit hangar
/seele military drain
/seele military status
```

等状态为干燥，再运行：

```mcfunction
/seele military door
/seele military visit gantry
```

平台落脚点为 `6446.5 127 -6217.5`。等待舱门完全开启；在平台上面对插入栓侧面的舱口右键，正常进入插栓流程。等背板关闭、机体抬头和驾驶画面恢复，再用 W 朝机库大门走出。

**UN-01 出舱顺序：**

```mcfunction
/seele military un01 visit control
/seele military un01 drain
/seele military un01 status
```

等状态为干燥，再运行：

```mcfunction
/seele military un01 door
/seele military un01 visit gantry
```

平台落脚点为 `6286.5 127 -6217.5`，同样右键真实舱口进入。两座 UN 机库位于地表，开门后直接驾驶出舱，不使用 NERV 地下弹射井。

- WASD 移动，Ctrl 奔跑，空格跳跃，Shift 下蹲，Z 趴下。
- R 切换武器，左键攻击／射击，右键重击或炮模式蓄力；G 控制 AT 力场，K 发射眼部激光。
- 回库时保持机体朝向出口（朝南，yaw 0），用 S 倒退回自己的原床位。停在床位三格以内，再按 V 退出，等待原插入栓被吊回平台。
- 离开 LCL 池范围，回控制室执行对应的 `door` 关闭舱门；等“干燥，舱门关闭”后执行 `fill` 注液。不要在机体未归位或有人仍在池中时注液。

UN-00 使用黑金装甲；UN-01 使用绿灰装甲、红色五角星与 UN 标记，已删除 CCCP 字样。两台背部开口、盖板铰链、激光出射点分别按实际新网格测量。可编辑源模型和离线预览见 [双机制作记录](UN_MODELS_R21.md)。

## 列车与城市警戒

列车采用每 60 秒一班的运行安排，站牌读取实际预计发车时间并显示北京时间；运行延误会反映在时刻牌上。停稳开门后直接从门口走入，再向车厢里面走两步。到站开门后走出；需解除乘坐状态时按 Shift。

金字塔附近可从 `30.5 -466 514.5` 进入 U2 站台。其余 P1、U1、U2 等站点及既有 NERV 三机测试命令见 [R20 操作表](MANUAL_ACCEPTANCE_R20.md)。本轮增加了地图标记，打开大地图即可查看；标记只显示在地图中，不会变成悬空的世界路牌。

当前默认使用 24 区块真实地形渲染，关闭此前出错的 LOD。启动器为 Java 指定独立显卡偏好；服务器可承担世界模拟，但客户端仍负责实际画面绘制。

以后联机时，服务器和客户端使用同版模组（本轮协议 30），玩家客户端安装本轮 `run/resourcepacks/eva_real_model` 资源包；新机体的图形资源由客户端加载。
