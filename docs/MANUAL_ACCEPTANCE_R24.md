# R24 操作与验收

使用仓库根目录 `start_eva_test_r24.bat`。启动器要求正式存档中存在 `r24_ready.json`；安装完成前会拒绝启动。`--check` 只准备启动环境。原三台 EVA、两台 UN、人员和玩家资料继续沿用原身份。

R24 已于 2026-09-19 安装并通过回读与启动准备检查。仍使用 `SEELE_TV_WORLD_PREVIEW_20260906`，无需选择另一个预览世界。先按下面的 NPC 出动和路径导引验收；密集 UN 战备区域的帧率限制见 [实测记录](PERFORMANCE_R24.md)。

## 先试一次真正的 NPC 出动

1. 带 NERV 员工卡进入大指挥室，右键美里。先问“初号机现在能发射吗”，确认只回答状态、没有按下按钮。
2. 在“指挥”页选初号机，提交“整备后发射初号机”。美里会等你登机，再走到对应控制台按真实按钮；整备完成、发射床锁定后才按发射按钮。
3. 沿原登机通道进入初号机插入栓，等待后颈对接与封口。关闭对话窗口不会取消已接受的指令。
4. 在驾驶舱内可用 `/nerv contact 美里` 或 `/nerv contact 律子` 打开通信界面，查询状态或请求回收。回收仍需把机体停在自己的地表回收台上。
5. 需要停止后续操作时，在通信页选择取消；已开始的机械步骤依其安全联锁处理，不能在移动中直接跳成“已停稳”。

单人验收缺卡时可使用：

```mcfunction
/give @s projectseele:nerv_employee_card
/execute in projectseele:geofront run tp @s 27.5 -407 282.5
```

这是有限指令系统，支持状态询问、整备、发射、回收、组合出动和取消，不是联网聊天模型。不同岗位有不同对白与权限；多人争用同一台机体时不会同时执行两套指令。

## 金字塔和机库导引

对话页点“道路指引”，或使用下列命令。导引会根据当前楼层、实测通路、门与电梯给出下一步；到达提示以人物真正走到目的地为准。

| 目的地 | 命令 |
|---|---|
| 大指挥室 | `/nerv route command` |
| 机库实际登机通道 | `/nerv route hangars` |
| 总部入构站 | `/nerv route station` |
| 金字塔近侧换乘站 | `/nerv route pyramid_station` |
| 发射区车站 | `/nerv route launch_station` |
| 贯通机库观察廊 | `/nerv route observation` |
| Terminal Dogma | `/nerv route dogma` |
| 停止导引 | `/nerv route stop` |

导引只覆盖已登记并验证的地下设施网络。它不会向未知地面区域画一条穿墙直线。路上的标牌使用主环廊、交通接驳层等用途名称；电梯提示仍保留具体目的楼层。

## TV 剧情

从美里的“作战记录”页接受当前作战，或使用：

```mcfunction
/seele tv status
/seele tv begin
/seele tv cancel
```

当前可玩内容按 TV 顺序是**第 1—2 话萨基尔首战、第 3 话夏姆榭尔迎击**。后续章节清楚标为制作档案，不能跳过未完成章节直接开后面的使徒战。UN 属于独立扩展，不插入 TV 顺序。一个世界共享同一份剧情进度。

驾驶初号机沿正常出动流程前往东北迎击大道。接近已接受作战的区域才会出现相应目标；参考作战起点约为 `356 81 -460`。首战须先削弱萨基尔，再在平整、有足够空间的区域接近，满足条件后进入约 23 秒自主行动演出。Enter 可以跳过演出的战斗部分，随后恢复操纵。演出期间普通 HUD 暂时隐藏，结束后恢复。

夏姆榭尔先蓄势再挥鞭，接触沿实际鞭链计算，实体墙能阻挡。普通拳、刀等近战用于中和 AT 力场，再攻击本体。原生战斗测试中的受控伤害只用于开发验证，不是要求玩家输入的通关指令。

## 既有交通和 UN 操作

列车／飞机登乘、每分钟班次、北京时间发车牌、UN 双机出舱和 `recover/reset`、坦克／飞机驾驶及汽车充电，继续使用 [R23 操作手册](MANUAL_ACCEPTANCE_R23.md)。本轮不要求换存档或重新生成机体。

默认仍为 24 区块真实地形，关闭有透视问题的 LOD。天空光初始化做了逐列等值优化；局部初始化加速不等于整段航班全程无卡顿。服务器能承担模拟和世界加载，客户端仍需处理收到的区块与画面。

若报告问题，请写上地点 XYZ、来向／去向、当前姿态或指令次序。尤其检查出动结束后的第一人称控制、回收台静止判定、岔路提示和新增陈设附近的实际行走。
