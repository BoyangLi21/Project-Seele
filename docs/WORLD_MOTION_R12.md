## 23 秒动作

本地 `run/projectseele-local-maps/first_battle_r12.json` 是 30 fps、691 帧的全身骨骼数据；服务器、模型、接触标记、插入栓接口和镜头使用同一时钟。原来的 460 tick 演出长度、372 tick 使徒死亡和 432 tick 开始交还视角的节点保留。

| 时间 | 表演与素材 |
|---|---|
| 0–5.35 秒 | 真人站姿衔接 CMU 18_03 拉扯，手掌约束在 AT 力场表面，随撕裂向两侧分开 |
| 5.35–8.5 秒 | 同步使用 CMU 18_05／19_05 双人交互；初号机右手约束到使徒左肘的实际蒙皮表面 |
| 8.5–10 秒 | Haley Tuffles 正蹬，修正靴子前缘接触；9.2 秒命中 |
| 9.2–11.7 秒 | 真人受推、倒地和起跳；11.6 秒切到落地机位 |
| 11.7–16.8 秒 | Tuffles 跪姿支撑，结合 Bandai Namco Research 职业演员连续重拳、腰胯扭转与手部接触；12.75／14.15 秒出拳、15.35 秒拔肋、16.05 秒刺核 |
| 16.8–23 秒 | 为使徒身体比例编排的包裹、自爆与回收动作，随后交还驾驶 |

这是一套动捕改编：跪姿出拳、怪物包裹以及对不同身体比例的接触修正包含人工编排。记录源文件和哈希，避免将生成的怪物动作描述成真人原始记录。最终使用 10 个源片段；另外保留选择过程中的素材清单。

修正了 BVH 六通道平移重复叠加、CMU 第零帧校准姿态、CMU 胸部零长度轴、手腕滚转和旧脚底锚点突然释放等问题。对高角速度突变做局部过渡滤波，主要动捕帧保持原来的发力节奏。随后重新约束关键接触，并从最终蒙皮姿态重算所有世界坐标标记。肋骨道具也使用持握手的朝向。

落地镜头使用显式切镜，避免跨机位插值穿过模型。地面检查覆盖最终网格，关键手部接触同时有端点误差检查；这些几何检查不等同于所有网格之间都不存在相交，最终观感仍需要人工验收。

两台角色共用有界连续播放时钟，对短暂同步间隔最多补偿两个 tick。死亡、交还镜头和演出结束须等待服务器确认；暂停、换场景和读档有独立处理。离线模拟网络抖动的 14 项行为检查通过；同一模拟中旧时钟出现 258 次无进展帧，新时钟为 0，最大提前量 1.978 tick，保持单帧内两台角色、镜头与接口取样一致。

## 吊机

在 R11 原创双梁卷扬机上增加倒角铸件、减速箱端盖、轴承螺栓、圆滑轮、维护走台、管式扶手、液压支撑、三爪夹紧机构和检查镜头。机械表面使用独立网格，静态部分缓存到 GPU；四根钢索、悬架和万向夹具随插入栓实际变换运动。

参考真实工业卷扬布局进行原创建模：[Konecranes CXT 电动钢丝绳葫芦资料](https://www.konecranes.com/sites/default/files/download/cxtelectricwireropehoist_2012_05_23_e.pdf)。该资料用于理解外壳、卷筒、走行机构的视觉结构。

## 私有素材与复现

素材出处：

- [CMU Motion Capture Database](https://mocap.cs.cmu.edu/)，18／19 号双人动作。
- [Bandai Namco Research Motiondataset](https://github.com/BandaiNamcoResearchInc/Bandai-Namco-Research-Motiondataset)，数据集许可为 CC BY-NC 4.0；此处用职业演员出拳。
- [Haley Tuffles Motion Capture Pack](https://haleytuffles.com/motioncapture)，使用正蹬、跳跃、倒地、落地、跪姿等片段。

含上述 NC 数据的成品动作保留在本机私有路径，不打包进 MIT 公共资源。公共程序优先读取经过时钟、长度、数值及曲线校验的私有文件；文件缺失或错误时回退到原公共 R10 演出。联机双方需要相同私有动作文件。

在已有合法本地源文件和私有模型的环境中：

```text
python tools/prepare_human_sources_r12.py
python tools/author_first_battle_r12.py
python tools/finalize_first_battle_r12.py
python tools/finalize_first_battle_r12.py --install
```

`--install` 要求最终检查通过且文件哈希一致；旧的本地 R12 文件会保存到本轮工件目录。中间稿不会自动覆盖运行文件。
