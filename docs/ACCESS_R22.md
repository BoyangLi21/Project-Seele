# R22 — 通路、铁路与驾驶验收修补（进行中）

本轮针对用户实际游玩反馈，基线为当前正式 TV 存档，施工副本为 `SEELE_R22_REVIEW`。冷备份记录在 `artifacts/access_r22/baseline.json`，包括当前世界、当前私有模型包和既有未提交文件哈希。

本轮明确目标：

- 删除 `-308 -466 729` 的迂回接驳，从 `-335 -466 739` 直接连接地下车站。
- 连通 `-28 -461 269` 西侧旧路，修复 `-29 -448 268`、`-6 -448 385` 一类平台侧边坠落风险；检查相连旧路网的所有岔口、端部与侧边。
- 地表铁路从多条短线整合为多站贯通线路，减少重复站台；换乘处建立直接步行连接，各站通往周边重要建筑的通道配置原 MTR 扶梯／自动步道。
- 列车增加两个车厢，并按实际车长校核站台、待避线与车辆段；维持每分钟发车，显示真实北京时间时刻表。
- 统一使用原 MTR 自动步道，替换上一轮自制的慢速地面带；检查速度、朝向及相邻通道净宽。
- 每个总部道路交叉口说明指挥室、机库、车站的方向；恢复站台实时发车显示。
- 播报把 NERV 作为单词读；提高 NERV—UN 航班速度并重新核对时刻、制动与曲线。
- 更新三名驾驶员的实际 Minecraft 角色皮肤，改善冬月的立体外观。
- 在 `13 -389 355` 配置真实可弹奏的钢琴模组。此处替换旧装饰钢琴的准确范围获得本轮单独授权，其余已认可指挥室布局保留。
- 修复直梯内人物上下卡顿，测试渲染帧上的人／轿厢相对位置，不能只检查没有坠落。
- 修复 UN 机体膝甲误连前臂，增加攻击姿势的检查；为两台 UN 机体提供保留原身份与胶囊的 recover/reset。
- 核实并说明 SBW 汽车充电操作。

已确认的原因：旧通行检查经过了用户指出的平台，但未覆盖路线两侧的整个可达平台边界；通行记录通过不能替代完整边缘检查。UN 网格旧分区中的 `abs(x)>arm_edge && y>65` 把部分外侧膝甲分入前臂，旧的手部裁剪范围也会误删腿甲。

本轮不再以“路线目录全部通过”单独作为整体安全结论。最终需要通路、全部公开边缘、换层／换乘、门禁与电梯实际动作分别提供证据。

车辆充电：当前 SBW 模组的 `charging_station` 使用燃料、食物或 FE 电源，给范围内载具充电；创造模式可使用 `creative_charging_station`。已对照本机 0.8.9.1 的中文说明及[模组官方 Wiki](https://github.com/Mercurows/SuperbWarfare/wiki)。

播报处理已加入 MTR 语音调用处：中文句子中的 NERV 使用“奈尔夫”音译，英文句子用 nerve 引导整词发音；界面、站牌、线路数据中的 NERV 保留原拼写。待原生语音调用验证。
