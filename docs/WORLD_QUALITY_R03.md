# R03 全图通行复核与建筑细节

本轮继续修改用户实际游玩的 `SEELE_TV_WORLD_PREVIEW_20260906`。种子和地区布局沿用 R02；重点是金字塔至机库／发射观察区的完整动线、遗漏的楼板破损，以及车站、机场和地下空间的细节。

## 发现与修复

逐层读取发现南城区 `tokyo_south/13-05` 和 `13-06` 的东侧与道路净空相交。两栋楼共有 11 个楼层、1,172 格室内楼板边缘已被切空。东立面由 X=157 收整至 X=152，补齐连续的外墙、窗框、楼板收边和屋顶边缘，保留门口和西侧楼梯。当前边界记录在存档的 `regional_quality_r03_structures.json`。

金字塔到达厅、东翼楼梯、B-40 转接梯、长移动步道、U2 机库站、机库电梯候梯口、中层机库和三处发射观察位组成了明确的人员路线。首次静态寻路试图从侧面登上转接楼梯，被原生碰撞实走拒绝；验证路线现从楼梯下平台进入，18 条完整往返路线已经实走通过。全程只在起点放置测试角色，途中保留真实位置和每个转角的落地过程。

机库站原先需要绕到站台端部的狭窄接缝。现于西端 `108 -442 -50` 开出三格宽的正式人员门洞，配有围护、顶棚和下方支撑；回廊接入既有机库电梯南侧候梯区。候梯区、轿厢和发射机械的原坐标保留。路线沿候车座椅旁的通行带进入门洞。

全量实走发现机场饰面有 39 格侵入了新箱根管制塔楼梯范围，已按开工冷备份恢复这些具体方块，机场饰面工具加入整个塔楼的保护范围。原 B-40 已装有并排扶梯，旧的 Z=274.5 坐标落在扶梯扶手上；普通楼梯的实际通行中心是 Z=273.5，复验使用这个实测入口。

补充地面检查把轨道槽和地下出入口从地形漏空候选中逐一分开：37,879 格属于当前铁路工程范围，399 格属于机场楼梯／下穿通道，均保留。其余 192 列为站边和路边未接齐的地面，按已测定的最终地形高度补齐 393 格；这些位置均在已经验证的道路范围与铁路净空之外。补齐后逐列回读，无剩余未归类缺口。

原 B-40 的两扇云杉门会让纯静态扫描显示为分隔空间。按原生开门规则检查后，指挥电梯、两翼和公共电梯通道属于同一通行网络。Terminal Dogma 的北侧平台和周边通路也纳入本轮复查；已退休的中央桥段不当成需要重新填满的地板。

## 精修范围

- 23 个列车站台：整理顶棚、通风格栅、候车带、座椅、服务柜和线路标识，保留原生登乘边缘。
- 两座机场：每座六组值机柜台、队列铺装、整齐的候机座椅、出发信息牌、服务设施、顶棚灯带、门廊收边和维修库细节。移除与新布置重叠的旧柜台及散置座椅。
- 地下空间：11 段主要走廊的墙面分缝、踢脚与灯具；总部到达厅的接待和等候区；22 间房间的照明、座椅、设备墙和门牌。
- 187 栋城市／机场塔楼：入口雨棚、壁灯、门牌、墙脚、转角收边和室内座椅尺度。
- 85 块原生文字标牌：用于总部、机库方向、房间、机场值机和站名，具有固定位置并随存档保存。文字显示实体不占角色或车辆的碰撞空间。
- 机库固定栈桥与可收回登乘桥：在对应维护函数中统一石材与低饱和区域色，解决离线饰面在进入游戏后被维护逻辑覆盖的问题。桥的几何、开闭流程和机体运输参数保持原值。
