# 初号机与使徒的支撑、腾跃和近身衔接 R18

旧战斗视频的下肢异常来自不相容的支点：脚被放到髋部两侧，却又要求膝盖贴地，求解结果会把膝盖折向内侧。旧记录中胫骨存在约 48–50°／33 ms 的突变。此次保留 23 秒演出顺序与既有真人动作来源，重做支撑与跨动作连接。

初号机的膝甲和脚尖使用实际渲染网格确定接触点。髋部在保持两条大腿长度的约束下转移重心；上身姿势相应调整，使支撑手和打击手仍能到达原有接触位置。腾跃采用连续抛物线，落地时由接触制动并收势；最后一击后的右手沿身体外侧撤回，双脚按顺序重新落稳再起身。落地音效和标题切换读取动作文件中的实际落地时刻。

使徒倒地后的腿改为向两侧展开并接触地面，再连续接入起身、两步接近和锁臂。保留完整机体外形，未恢复 R14 的顶点包覆变形。踢中后的退移立即响应，并给初号机腾跃留出净距；落地后的两者相对位置保持一致。数值伤害、HP、武器冷却及普通自由行动的跳跃参数没有随这段演出修改。

验证包括编码后重新解码的网格落地、膝甲接触、脚部漂移、支撑和打击手位置、世界空间旋转连续性与抛物线加速度。另用 Blender BVH 和精确三角形分离轴检查两机之间的穿插；手掌、手指及近身支撑的接触单独记录，不把所有接触都误判成必须拉开距离。

新版数据先通过 `firstBattleReviewClip` 参数在 `SEELE_FIRST_BATTLE_REVIEW_R10` 中测试，避免未验收候选接管正式演出。正式数据位置为本机私有 `projectseele-local-maps/first_battle_r18.json`；R15 文件保留作为回退。原有用户修改的基础动作和 00／02 几何文件保留。

复现流程：`refine_grounded_battle_r18.py` 生成支撑姿势，`author_clinch_r15.py --lateral-detour 0 --keep-hero-arms` 连接新的倒地姿势，`finalize_grounded_battle_r18.py` 完成净距与落地事件，随后运行 `audit_grounded_battle_r18.py` 和 `bake_grounded_battle_r18.py`。本机工件位于 `artifacts/grounded_battle_r18/`。原生游戏录像使用直接 JPEG 编码和实际采集时序，不插帧；混音为按事件同步的原创音效。

最终候选通过接地、接触、旋转连续性与重力轨迹检查；重点交互阶段合计 514 个姿势／插值样本，没有头部、躯干、腿、脚、肩塔和背部机构之间的跨机体穿插。手部和少量前臂近身接触保留。完整 18 项原生检查通过：真实攻击触发、正常完成、跳过、缺失角色恢复、同一驾驶员与机体重载续播，以及结束后的相机、碰撞和移动恢复。报告为 `native_full_checks.json`，最终候选指纹为 `ae85a886f76613dfb967ee681dc61e3b9823d9bf90d23cd9a99c061ab47b9631`。

最终预热录像再次通过 9 项完成和控制恢复检查，原生加载指纹与候选完全一致。采集 521 帧／23.63 秒，游戏中位帧率 48 FPS，写帧队列丢帧为零；成片 `review/eva_sachiel_r18.mp4` 为 23.677 秒、约 4.97 MB。该版本已通过安装脚本写入私有正式动作文件，R15 回退文件保留。画面采用实际时序，不能把游戏中位帧率当成成片恒定帧率。
