# R35 战斗与机库机构重做

R35 重做了受击、失衡、落地和恢复的身体控制，并修正转移架、LCL 遮挡及发射反馈。R34 已被负责人否定，本版另做原生检查；下面区分实现范围、验证结果与仍需人工判断的手感。

## 战斗

- EVA 和萨基尔失衡后，由有关节限制的身体模拟接管。膝、肘、髋、肩分别运动，与真实地图碰撞；随后从落地姿势接入翻身、撑地、起身。没有用整体模型旋转代替倒地。
- 膝和肘使用明确的解剖转轴，不再从弯曲的绑定姿态推断转轴。五台 EVA 分别使用自己的骨长、关节中心和装甲形状。
- 后续交叉拳、勾拳主要通过落脚支撑和腰肩转动发力；前进拳、重击和暴走动作仍可迈步。避免每次输入都同时换两只脚。
- 近战接触检查使用随骨骼移动的身体表面。倒地的碰撞范围随身体变矮，普通追击不再无限重启同一段起身。力场仍有独立的接触范围。
- 萨基尔主动逼近，组合使用长臂推压、前臂光枪、勾击、砸击和对低姿态目标的踩踏。移除了上一候选里频繁绕圈、读出拳准备就闪避的行为。
- 站立近身间距依据当前躯干装甲计算，水平移动瞬间的假离地标记不会关闭它。地面出拳的位移由服务器统一执行，收势后交还驾驶，避免客户端和服务器重复推动、纠正机体。
- 暴走保留驾驶员在插入栓内，锁定手动操控；机体自行转向、逼近、挥击。取消旧的自动赶出驾驶员逻辑，也不会一边倒地一边继续执行进攻位移。
- 受击记录位置、方向和动作中的动量；躯干撞地时才触发落地声和扬尘。粒子按巨型机体的观察距离发送，避免驾驶员在高处看不到脚部效果。
- 完整的录制起身动作保留翻身、手部撑地和脚部承重，压缩了中间坐姿停顿。起身完成时按地图真实地面交还驾驶控制。
- 机体损毁会终止暴走进攻，保留落地后的姿势和碰撞范围供回收；萨基尔不再把已经损毁的机体作为可攻击目标。

普通控制阶段仍由动作和支撑约束驱动，失衡阶段才转交动力学。这不是全动作 Motion Matching，也不等于已经达到商业 3A 游戏的完成度。第一幕的旧剧情编排没有被描述为本轮全部重拍。

## 机库与发射

- 转移架补齐横梁、固定轴座和底座导轨。夹具伸缩时活塞杆仍连接固定端，电缆卷盘及夹具不再仅依赖悬空零件。
- LCL 移除重复的深度遮挡面，并提供单独的 Complementary LCL 兼容版本。保留琥珀色，改善从上方观察水下机体。
- 弹射加入实录液压机素材和固定泄压口的短促蒸汽。音效和粒子的发送范围覆盖驾驶舱。
- 修复另外两台机体在地表且未加载时，机库中剩余机体的准备流程也被全局等待卡住的问题。仍保留原机体身份，不以重新生成机体解决它。
- 转移中的客户端机体、插入栓和驾驶员独立同步机械位置，避免旧区块卸载后普通实体更新停止、模型却还在沿动画移动的循环依赖。显示边界与整副转移架共用这一个位置。

## 操作和验收

入口为 `D:/eva/start_eva_test_r35.bat`，`--city-shaders` 使用含 LCL 兼容修正的光影，`--no-shaders` 使用普通渲染。正式存档仍为 `SEELE_R31_WORLD`。

- 空手左键为普通攻击，右键为重击。移动后连续出拳，观察落脚、腰肩发力及收势。
- 逗号键 `,` 接近可抓取使徒后抓住，再按一次投掷。跳跃中使用攻击；趴下时不允许跳跃。
- `G` 开关 AT 力场，`R` 切换已有武器，`O` 呼叫指挥通信，`V` 弹出。
- 让双方实际击中、倒地、起身后继续移动与攻击，检查是否掉穿、瞬移、长期卡住或反复播放起身开头。
- 完整走一次插栓、转移、发射、回收，观察架子的固定端、LCL 透明度、弹射的液压音与烟雾。

伤害和生命值保持原设定。相对已安装 R33：普通拳基础动作时长由 24 / 27 / 29 tick 改为 23 / 25 / 27 tick；普通拳同步率加速上限仍为 1.08；空手普通拳 / 重击基础伤害仍为 20 / 35。连续失衡阈值由 2.25 改为 3.20，踉跄初始位移速度系数由 0.85 改为 1.60。重击仍可直接造成失衡。

暴走逼近从原来的寻路速度倍率 1.45 改为受转向、地面和接触约束的直接移动，上限 1.6 格/tick；两者单位不同，不能理解为单纯提高 0.15。暴走伤害倍率仍沿用原配置。

客户端和服务端须同时更新至协议 **39**。运行配置必须与模组匹配；旧存档不包含在运行更新包中，也不由安装脚本覆盖。

## 原生检查记录

- 跳跃出拳、跳跃重击、抓取、投掷、双方受击起身完成实际流程；两种跳击各产生 32.2 点结算伤害，抓取掌面最大偏差约 0.0023 格。投掷后的位移约 62.8 格，使用实际身体落地。
- 最终普通交战产生双方实际伤害，并在倒地、起身后继续移动和攻击，没有掉穿测试地板。UN-01 的站立、接触、重击和移动中攻击完成检查，连续载具位置纠正已消除。
- 初号机和 UN-00 的损毁姿态保存了真实的低矮碰撞范围，分别约 17.2 和 18.3 格高。没有以生成替代机体完成回收。
- 暴走测试没有注入玩家攻击输入；修正朝向及躯干净空后，机体能够自主逼近、击中并承受反击。它不是无敌模式。
- 机库以原机体身份完整经历插栓、转移、发射、回收；驾驶客户端各收到一次液压启动与弹射事件。跨区块后绘制与实体更新持续推进，机体和整副转移架均可见。
- LCL 分别查看了普通渲染和实际启用 Oculus 的兼容光影画面。实录视频保留实际帧间隔和游戏扬声器回录，没有另配战斗声音。
- 本机低频截图的双机交战平均约 75 FPS、后段约 85 FPS。改用后台 JPEG 编码后，正式录制平均约 63 FPS、后段约 74 FPS，截图零丢帧、零写入错误；这些数值属于当前机器和测试场景，不是其他地图或设备的保证。

这些检查不替代手感和美术验收。最终普通对打日志仍有一次约 0.54 格的常规载具位置校正；没有把它描述为完全零抖动。旧第一幕整段演出、其余使徒的全部动作和正式服务器多人延迟体验，也不属于上述检查已经证明的范围。
