# R29 第一幕「首次出击」完整操作

这是目前可玩的 TV 第 1—2 话萨基尔迎击：接受任务、亲自登上初号机、整备发射、前往战区、实际战斗、约 23 秒自主行动演出、归档与回收。它不是把原作两集从接站到医院逐镜完整播放。第二章为第 3 话夏姆榭尔；更后面的档案仍未做成可玩章节。

## 1. 启动与确认进度

本地双击 `start_eva_test_r29.bat`，使用正式存档 `SEELE_TV_WORLD_PREVIEW_20260906`。服务器部署时，Server、World、Client 必须都使用本批 R29。一个世界共享一份 TV 章节进度。

进入后先输入：

```mcfunction
/seele tv status
```

首次游玩应显示「第 01–02 话 / 首次出击」，尚未下达本章指令。若已经是夏姆榭尔，说明第一章已归档；不要继续输入 `tv begin` 并以为它会重打第一章。

带上 NERV 员工卡与卫星电话。测试服管理员可用：

```mcfunction
/give @s projectseele:nerv_employee_card
/give @s projectseele:satellite_phone
```

剧情接受需要 NERV 通行权限；管理员也可直接执行。整备、发射、回收的维护命令需要管理员权限，普通玩家通过电话让有权限的 NPC 操作。

## 2. 降下城市并接受正式剧情

先用电话联系冬月，执行城市沉降；等待楼群完全降下、广场平整后开始作战。楼群未降到底时，任务会等待，不会在建筑中生成使徒。战斗期间禁止升起城区。

手持电话右键，联络美里，在「作战记录」里点「接受当前作战」；也可以输入：

```mcfunction
/seele tv begin
```

看到「作战已接受」及「前往中央可升降城区」后，任务已登记给当前玩家。首次出击由**你亲自驾驶 NERV 初号机**完成。不要派真嗣 NPC 替你登上初号机，也不要使用 UN-00、UN-01 或其他机体替代。

资料室旧终端和 `/seele firstbattle begin` 启动的是独立迎击。要正常推进 TV 章节，请使用上面的 **`/seele tv begin`**。

## 3. 去机库并登机

在总部内可输入：

```mcfunction
/nerv route hangars
```

跟随引导到机库登机通道，再去中间的初号机。只想快速测试的管理员，可在**尚未乘坐机体时**传送到其登机廊：

```mcfunction
/execute in projectseele:geofront run tp @s 30.5 -394 -267.5 0 0
/seele eva status unit01
```

正常开始状态是 `PARKED`（机库待命）。沿登机桥到机体背后的悬挂插入栓，空手对准插入栓侧面的真实舱口右键进入。若已有真嗣 NPC 占用，在电话中选初号机「下机返回待命」，等他离开；管理员也可用：

```mcfunction
/seele eva dummy stop unit01
```

如果初号机还在地表，先按第 7 步正常回收。不要反复生成另一台初号机，也不要直接删掉原插入栓。

## 4. 整备与发射

登机后按 **O** 打开指挥通信，联络美里，选初号机「整备后发射」。她会去按实体控制台按钮，等整备和发射联锁满足后继续执行。也可分开请求整备、发射。

管理员分步测试指令：

```mcfunction
/seele eva prepare unit01
/seele eva status unit01
```

等待登机桥收回、吊机接入插入栓、背部锁定、LCL 排出、转移架升起接电、机体沿斜坡到发射床。看到 **`SILO_READY`** 后再输入：

```mcfunction
/seele eva launch unit01
```

不要在转移中提前重复发射。地下弹射为本图约 164 tick（8.2 秒），起步猛烈弹射，随后减速上升；到地表后仍要等支撑、舱门及解除锁定完成，再开始移动。新地表电桩在井口南侧，初号机对应 `30 81 3`。

## 5. 前往战区并战斗

驾驶初号机前往地表**中央可升降城区**，参考脚部坐标 **`32.5 81 195.5`**。从初号机井口 `30.5 81 -35.5` 出发，整体方向为 **+Z（南方）**。顶部任务条显示到达距离。进入约 **90 米**范围后，本次任务的萨基尔自动出现；不要另用 `/summon` 生成替代目标。

驾驶中不要用玩家 `/tp` 越过流程，它只会影响乘坐关系，不能代替驾驶机体到达。

| 默认操作 | 功能 |
| --- | --- |
| WASD / Ctrl | 移动 / 奔跑 |
| 空格 / Shift / Z | 跳跃 / 下蹲 / 趴下切换 |
| R | 切换已装备武器 |
| 左键 | 普通攻击、持枪时射击 |
| 右键 | 近战重击 |
| G | AT 力场开关 |
| O / F5 | 指挥电话 / 视角切换 |

以自己当前按键设置为准。先用拳或渐进刀等近战削弱使徒 AT 力场；步枪在 AT 力场存在时无法有效伤害它。力场降为零后继续攻击本体。第一幕建议使用拳，便于控制最后的血量；别在残血时继续无休止地重击。

## 6. 触发演出与确认通关

当萨基尔生命降至 **32% 或以下**，同时满足以下条件时，自动进入自主行动：

- 你仍亲自驾驶正常供能的 NERV 初号机，发射流程已经结束。
- 初号机**站立**，没有蹲着或趴着，不使用 N² 武器。
- 与使徒水平距离约 **14–46 米**，脚部高差不超过 **4 米**。
- 机体站稳，脚下有实际支撑，周围足够容纳双机演出。尽量留在沉降后广场中央，避开建筑、轨道和陡坡。

看到「制御不能 — 初号机进入自主行动」后，放开移动和攻击。演出接管双机，依序完成破开力场、近身打击与使徒最后的自爆，结束后恢复操纵。**Enter 可跳过演出的战斗部分**；首次验收建议完整观看。

血量够低却不触发：先停止攻击，松开 Shift，若趴着则按 Z 起身；在平地调整到约 20–35 米距离，等机体停稳。若仍不触发，检查电源和附近障碍。不要用击杀命令代替任务结算。

结束后输入：

```mcfunction
/seele tv status
```

显示**已归档 1 章**，当前推进到**第 03 话 / 第二次迎击**，才代表第一幕正式完成。若萨基尔自然死亡也会按登记目标结算，但可能错过完整的双机演出。

## 7. 回收初号机

驾驶回到自己的地表回收台中心 **`30.5 81 -35.5`**，站稳、停止移动。按 O 联络美里或律子，选择初号机「回收」，或管理员执行：

```mcfunction
/seele eva recover unit01
/seele eva status unit01
```

等待下降、回库、机体固定与恢复 LCL，最终状态回到 `PARKED`。按 **V** 申请离开插入栓，等待退出流程完成再走出。TV 第一幕的归档与回收是两个步骤：战斗归档后仍需把机体带回机库。

## 中断、重来与 NPC 对话

任务中离线后再进入，现有剧情和原机体身份会保留；如驾驶连接未能自动恢复，先检查原插入栓，不要生成替代机体。

尚未通关而想重来时：

```mcfunction
/seele tv cancel
/seele tv status
```

等待取消完成，再接受本章。取消不计通关，也不会瞬间把 EVA 送回机库。若提示独立迎击占用，可查询 `/seele firstbattle status`，确认是自己的旧独立行动后，用 `/seele firstbattle cancel` 结束它，再接受正式 TV 作战。

已经通关而只想重看萨基尔，可由管理员启动独立 `/seele firstbattle begin`；它不会把 TV 章节倒退，也不会再次计入第一幕归档。测试完整首次剧情应使用自己事先保存的未通关存档副本，不要覆盖正在游玩的服务器进度。

R29 的对白扩展为 **230 条原创中文文本**。右键 NPC 仍直接在聊天栏说话；电话可问值班、同步、插入栓等话题。真嗣、丽、明日香有不同的待命、登机和驾驶通信，登机、转移、出击、受击、低电量、回收会选择对应台词。巡航闲聊有较长间隔，避免刷屏。它们是文字通信，未冒充原演员配音，也不会代替玩家替初号机发言。第一、二章中屏蔽丽和明日香的自动参战频道，岗位权限保持不变，警卫不会获得发射权限。
