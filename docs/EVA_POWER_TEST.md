# EVA 电力、脐带与冷机状态人工测试

这套系统把 EVA 的动作、眼部发光、武器输入和 A.T. 力场统一绑定到服务端权威电源状态。机库里的空机体必须是没有驾驶员、没有插入栓控制回路、0 电、黑眼、双臂下垂的冷机；插入栓完成 LCL/A10 准备并进入机体后，脐带才接通并开始充电。

## 默认数值

| 项目 | 默认值 | 配置键 |
|---|---:|---|
| 内置电池 | 6000 tick（5 分钟） | `eva_power.capacityTicks` |
| 脐带连接半径 | 32 格 | `eva_power.umbilicalRange` |
| 外接电维修 | 每秒 1.0 生命值 | `eva_power.repairPerSecond` |
| 从 0 充满 | 100 tick（5 秒） | 固定充电曲线 |
| 重大损伤断缆阈值 | 单次真实机体伤害达到最大生命的 15% | 固定安全机制 |

这些值不改变武器伤害、使徒血量或 A.T. 力场容量。

## 连续地图验收

1. 运行 `/seele geofront setup`，旧地图可先运行 `/seele geofront link` 触发有界修复。
2. 三个地下湿式机库和三个地表发射站各有一个供电桩，共 6 个；开发者也可用 `/give @s projectseele:umbilical_pylon` 单独测试。运行 `/seele geofront sortie_audit` 必须通过。
3. 运行 `/seele eva reset all`，观察三台 EVA：
   - HUD/指挥室读数为 0；
   - 眼睛不发光；
   - 双臂自然垂在身体两侧；
   - 不拿着上次出击的武器；
   - 无人状态不能走、转身、攻击或展开 A.T. 力场。
4. 让真人或 `/seele eva dummy start unit01` 进入外置插入栓。仅登乘、尚未按 PREPARE 时，驾驶舱保持黑暗，EVA 仍是冷机。
5. 在机库控制台按 PREPARE。确认 LCL 上升、A10 同步、插入栓三段式入体完成后：
   - 眼睛亮起；
   - HUD 显示“外部供电 / 充电中”；
   - 电量从 0 在约 5 秒内升至 6000；
   - 第三人称看到从供电桩垂到背部的橙色脐带。
6. 指挥室的 `POWER UMBILICAL/INTERNAL`、当前电量和驾驶 HUD 必须一致。
7. 指挥室下令发射。计划内的机库运输和 522 格连续发射井运动不会把脐带误判为战损；到达地表供电站后可以接上该站电源。
8. 驾驶 EVA 离开地表供电桩 32 格以上。脐带必须掉落且不能因走回原处而自动“穿回”机体，HUD 切换为接近 `5:00` 的内置电池倒计时。
9. 另一种断缆方法：接外电时让单次真实机体伤害达到最大生命的 15%。必须出现断缆警告和电火花，并切换到内置电池。
10. 为加速耗尽测试，对最近机体执行：

    ```mcfunction
    /data merge entity @e[type=projectseele:eva_unit01,limit=1,sort=nearest] {SeelePowerTicks:80}
    ```

    约 4 秒后，眼睛熄灭，移动、跳跃、姿态、武器、蓄力和 A.T. 力场全部停摆；驾驶员仍可执行紧急弹出。
11. 把 EVA 正常回收到自己的湿式机库。回收完成后必须重新回到 0 电冷机状态；下一次出击重新经历插入栓、LCL、接电和充电。

## 多人验收

1. 两名玩家分别驾驶两台 EVA，电量、断缆和损伤必须各自独立同步。
2. 第三名玩家留在 NERV Operations。其战略屏读数必须与两名驾驶员 HUD 一致。
3. 让其中一台断缆并退出重进；剩余电量必须从存档值继续，不能回满。
4. 驾驶员的真实第一人称直播只送到有权限且实际位于指挥室附近的观察者；训练驾驶员使用服务端合成传感器图。

## 离线门禁

```bat
python tools\validate_eva_power_contract.py
```

该门禁检查注册、同步/存档、五分钟电池、充电、断缆、统一控制锁、冷机动画、发光眼叠层、可见脐带、指挥室遥测和连续地图供电点。它不能替代玩家对眼睛亮灭、线缆观感和五分钟压力的实机判断。
