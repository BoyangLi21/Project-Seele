# R29：城市迎击与联合国运输

使用 `start_eva_test_r29.bat` 进入原正式存档 `SEELE_TV_WORLD_PREVIEW_20260906`。客户端和服务器须一起升级到 R29；网络协议为 **33**。

## 联合国电话

```mcfunction
/give @s projectseele:un_satellite_phone
/un phone
```

手持电话右键打开联合国通信。驾驶 UN 机体时按 **O** 也会进入此界面。选择 UN-00 或 UN-01，填写投放位置 **X、Z**，再点击投放。高度由地面与净空检查确定；原位置不合适时，系统会在附近寻找安全位置，并明确报告最终坐标。

电话是独立的 UN 指挥系统。持有电话、管理员或实际 UN 驾驶员可以使用；不会给 NERV 普通警卫添加发射权限。已由其他玩家驾驶的机体，由该驾驶员本人呼叫运输。

```mcfunction
/un status
/un deliver 00 32 195
/un deliver 01 -800 600
/un recover 00
/un recover 01
/un cancel 00
/un cancel 01
```

**投放流程：** 加载原机体和目标区域 → 检查地面及运输机净空 → 排液、开门 → 原插入栓完成接入 → 自行载台出库 → 运输机展开吊架、锁紧 → 爬升巡航 → 垂直下降 → 解锁。机体、插入栓和驾驶员沿真实航程移动，原机体身份保留。

**回收流程：** 运输机接载 → 返回基地 → 落在自行载台上 → 送回原库位 → 保持对齐并自动退栓。等待通信显示回收完成后再离开登机区域。

无人投放后，可走到机体附近，用电话选择“接入驾驶舱”。管理员也可输入：

```mcfunction
/un board 00
/un board 01
```

取消在安全阶段执行；已经升空的机体会安全返回，不会直接在空中放开。载人运输遇到驾驶员离线时保持位置，重连后继续原任务。接入尚未完成、落点有障碍或区域未加载完成时，查看电话里的实际状态。

机库操作：

```mcfunction
/un drain 00
/un door 00
/un fill 00
/un drain 01
/un door 01
/un fill 01
```

排液完成后才能开门；关闭舱门、机体归位且驾驶员离开后才能注液。运输正在使用机库时，手动机库操作会受到联锁限制。

日常回收使用 `/un recover`。故障处理时，管理员可以使用既有维护复位指令；它会中止该机体的运输任务，再复位原机体和原插入栓：

```mcfunction
/seele military reset 00
/seele military reset 01
```

## 核能与 UN-01 飞行

两台 UN EVA 都使用核能，不再连接电缆或消耗五分钟电池。HUD 显示“核能反应堆 · 在线”。驾驶、插入栓和机库联锁仍然有效。

UN-01 完成接入并离开机库后，以站姿按 **F** 开启飞行：

| 按键 | 功能 |
| --- | --- |
| WASD | 平移 |
| 空格 | 上升 |
| Shift | 下降 |
| Ctrl | 加速 |
| F | 自动降落；再次按下恢复悬停 |
| R / 左键 | 切换武器 / 开火 |
| K | 眼部激光 |
| O | 联合国通信 |

前进稳态速度约 33 m/s，Ctrl 加速约 56 m/s；输入有加减速过渡。UN-00 没有飞行系统。运输夹具锁定、低姿态或机库内不能开启飞行。

## NERV 发射与射击

- 步枪基础间隔 **3 → 2 tick**，约 **6.7 → 10 发/秒**；单发伤害仍为 **22**，NTW-20 音效保留。
- 发射改成强起步、随后放缓。当前地图井内全程 **33 → 164 tick**，即约 **1.65 → 8.2 秒**；最初 12 tick 上升约 69 米，地表解除支撑仍为 18 tick。
- 三座机库通往转移通道的大门顶部为 **Y=-370**；上方竖井尺寸和 UN 基地大门不跟着改变。

```mcfunction
/seele eva prepare unit01
/seele eva status unit01
```

等待 `SILO_READY` 后：

```mcfunction
/seele eva launch unit01
```

## 第一幕现在在升降城市中心进行

先联系冬月，在电话的城市页选择降下城市。等待建筑降到底、地表设施收拢后，再驾驶初号机接近中心迎击区。管理员可查询或操作：

```mcfunction
/seele tokyo3 status
/seele tokyo3 retract
/seele tv status
/seele tv begin
```

第一幕参考起点改为 **`32.5 81 195.5`**，位于以 `32 80 217` 为中心的升降区域。城市未准备完成时，任务条会说明原因；交战中不能用普通城市指令升起建筑。

仍需亲自驾驶 NERV 初号机：近战削弱 AT 力场，再把萨基尔本体生命降到 32% 以下；站立、保持 14–46 米距离并留出平整空间，即可触发演出。结尾增加核爆闪光、烟云、冲击波、十字架和低频爆鸣；演出结束查询 `/seele tv status`，确认归档后回收。

```mcfunction
/seele eva recover unit01
```

回收台仍在 **`30.5 81 -35.5`**。初号机与 UN 的回收指令分别对应各自系统。

## 本轮战斗动作验收

萨基尔出拳有肩胯蓄力、向前驱动和回收，骨枪沿同一条实际手部轨迹判定；夏姆榭尔挥鞭带动躯干，冲击方向来自鞭子运动。EVA 承受实际机体伤害后按来袭方向后仰或侧倾，再制动回正，维持移动与武器控制。力场完全挡下的攻击仍表现为力场反馈。

分别观察站立、移动、持枪时遭受正面与侧面攻击：不应每次都向同一方向点头，也不应反复弹簧式晃动。使徒伤害、血量及攻击周期没有调整。

完整第一幕操作见 [FIRST_ACT_R29_CN.md](FIRST_ACT_R29_CN.md)。

光影开启时，EVA 装甲使用兼容的实体顶点路径，避免旧 GPU 快速绘制漏掉刚性装甲。较密集场景和录制时负载仍较高，光影不作为本机实时帧率保证。
