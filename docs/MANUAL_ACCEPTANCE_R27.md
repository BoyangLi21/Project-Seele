# R27：冬月城市控制与机库 F5

本地启动：仓库根目录 `start_eva_test_r27.bat`。服务器请整批更新 R27 的 Server、World、Client 三个 ZIP。

## 冬月

冬月已从后方休息区调到大指挥室最高的司令席旁，岗位脚位 `27 -406 277`，面朝指挥大厅。保留原 UUID、皮肤和既有身份；未改动指挥室布局。

拿着卫星电话右键，或在 EVA 内按 **O**，从通讯录联系 **冬月**，选择 **城市** 页中的 **城市升起／城市降下**。也可以在通信文字框输入这两条指令。冬月会走到该席两侧原有按钮前操作，再回到岗位。右键 NPC 仍只显示聊天，不弹对话框。

近距离文字命令：

```mcfunction
/nerv talk fuyutsuki 城市降下
/nerv talk fuyutsuki 城市升起
```

城市升降沿用原有运行联锁；已有故障、已到目标状态时会返回原因。只有冬月拥有此岗位权限；玩家仍需 NERV 通行证或管理员权限。

## 第三人称

进入插入栓并整备初号机，在机库、转移途中和发射井按 **F5** 切换前后视角。机体锁定于机械流程时，镜头以脚位上方 **48 格的胸肩高度**为中心，修复原先逐渐下降到 **30 格腰胯高度**的问题。墙体仍限制拉远距离，所以井内是上半身近景，不强行穿墙取得全身画面。第一人称、自由作战镜头和插入栓未连接时的镜头未改。

已有机体出动、UN 双机、火车与飞机操作继续参考 R26、R23 手册。
