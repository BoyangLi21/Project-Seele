# R31 对白与广播

角色对白现在只以文字显示。使徒来袭时，摩耶、美里、律子的报告不再调用 `SoundSource.VOICE`；保留的声音是以设施名义播放的一次战斗配置广播，以及机械与警示音。电话的接通提示音仍是提示音，没有把 NPC 文字拿去朗读。

## 人物写法

`profiles.json` 的 253 句全部重写，原主题键保持不变，没有给警卫增加发射权限，也没有改变 NPC 对控制台的实际操作。

| 人物 | 本轮对白方向 |
| --- | --- |
| 美里 | 工作时果断、关注孩子的处境；向司令报告，不把司令当初学驾驶员训话。 |
| 律子 | 专业而简短；说具体的检查情况，不反复讲“反馈”“联锁”和抽象道理。 |
| 冬月 | 称玩家为“碇”，话少，保留老同事与副司令的距离。 |
| 摩耶 | 认真、略有迟疑；向司令用敬称，提到律子时仍有后辈的语气。 |
| 真嗣 | 需要父亲认可，但不在每一次战斗报告里重复这一点；受击时先有直接反应。 |
| 丽 | 寡言、平静，使用简单的人话，不把她写成诊断程序。 |
| 明日香 | 好胜、急于表现，战斗时有锋芒；面对司令仍保留基本上下级关系。 |

岗位角色只谈各自能负责的事。机库控制的动态回复也缩短了；遇到中止时会说实际中断原因，不再把“通信、权限、超时”三个原因一并读出来。

这是基于 TV 时期设定的项目原创中文对白，不是原剧逐字转录。人物的具体表达仍属于二次创作，不宣称等同原编剧。

## 广播处理

- 重新生成 18 个预录设施语音；使用 Microsoft 标准 `zh-CN-XiaoxiaoNeural`，`rate=+2%`、`pitch=-2Hz`，不模仿任何演员。
- 一次只报告一件事，例如“插入栓锁定”“机体转移。请离开轨道”。去掉无依据的“同步正常”宣告。
- 去掉原来的强制语速压缩；单声道 48 kHz，温和滤波，目标 -20 LUFS、真峰值 -3 dB。自然句间停顿保留。
- 相距 140 格内的机库共用广播时隙，避免三台机体同时播出三份相同提示。旧阶段的信息不会排队等到过时以后再播。
- 倒计时遵循真实发射秒数；如有普通报告尚未结束，先停止那段报告再报数。不会为了排队而改变机械时序。
- 同区域警示音每 60 tick 最多一次，播放语音时避让。没有替换为原剧音轨。

资源已经放进 `src/main/resources/assets/projectseele/sounds/`，沿用原来的事件名，新增 `pa_combat_r31`。生成脚本为 `tools/build_facility_audio_r31.py`；可试听的串联片段、每段时长与 SHA-256 在本机 `artifacts/dialogue_audio_r31/`。机械音、交通播报系统、战斗伤害和冷却未改动。最终听感需要人工试听。
