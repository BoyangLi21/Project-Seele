## 已实施

- **双格扶梯和站台**：14 组站房，独立升降梯段、普通楼梯、跨线桥、换乘管廊、玻璃候车区、座椅、照明、触觉警示和原生站台门。修复柱子、柜子、候车室与接驳路的冲突。平面步道去除扶手。最后清单为 21,918 台阶格、10,959 完整双格、零孤半、零遗留平面扶手。
- **铁路**：地表合并为 R1/S1，R1 六节、S1 四节；地下 U1/U2 与 F1/F2 保留。S1 坡道重建，R1 绕开两栋原公寓；站台原中心、标高及 ID 保留，R1/S1 停靠段为 130/100 米，门位按原车门节距对齐。站台门使用原生自动开门标志，静态围护与车门不互相替代。
- **时间与交通**：28 块新地表实时牌绑定原生站台 ID，显示北京时间。四条列车线与 F2 实际排班均为 60 秒。NERV 播报按整词发音。F2 巡航限速配置由 300 提高到 540 km/h，滑行与进近保持原设置。
- **金字塔**：50 个登记房间入口接入公共动线；277 处可达边缘补透明围护。16 条长廊加宽为五格净宽，布置 37 段双向原 MTR 步道，房门、岔路和楼梯前留出静止空间。78 块新导向牌覆盖 80 个路口，三个目的地均有实际通路。指挥室真实入口为 28/-406/272，门外固定按钮在 27/-405/270。
- **机库**：补齐三湿舱后门两侧固定封边及侧壁，清除 1,672 格舱外 LCL。六个前后观察位采用保留碰撞的透明承重面；常驻运输架上部整板改为检修视口，保留完整侧轨和顶部横梁。后侧实景已能看到机体头部，运输架仍常驻。
- **电梯**：修复原模组的运动向量错误、客户端发送位置的次序、到站侧壁接触、顶棚纠正和下降跳跃。另修复上游函数重写 bounds 参数后，补丁重复进行世界坐标变换、无法找到实际乘员的问题。没有全局关闭碰撞或靠免伤掩盖问题。
- **UN 两机**：保留既有身体与骨架，重建手掌、五指和腕口，校准正中光学组件及激光发射点。00 为 239,090 三角，01 为 222,409 三角，各 64 部件／87 骨。膝区无手臂权重，法线和权重检查通过。正式私有资源包已更新。
- **战备**：新增 144 件真实可用的 SBW 装备，使原 16 件增至 160 件：36 坦克、27 战机、9 攻击机、9 直升机、9 支援车、54 防御武器。分配独立车场、36 个飞机库位、九个直升机位及防御阵地，保留原跑道与两座 EVA 试验舱。
- **人员与设备**：三位训练驾驶员使用用户本机完整皮肤；冬月增加后梳灰发、眉毛、领口和外套几何。13/-389/355 的 Grand Piano 可实际演奏。增加 `/seele military recover|reset 00|01`，回收原机体和原插入栓，不生成替代实体。
- **全图遗留物**：组件扫描覆盖 53,188 个已生成完整区块、3,297,656 个 section，移除 8,539 格确认孤立的土石、植被与旧铁路碎片。保留原指挥显示和由实体钢架承重的吊机；修复新机库灯和标牌支撑。
